# M20 Pro 巡检系统 · UI重构方案

## 设计方向

基于huashu-design skill指导，采用**信息建筑派 + 东方极简**融合风格：
- 深色主题，专业监控界面
- 高对比度数据展示
- 清晰的视觉层级
- 克制使用装饰性元素

## 配色方案

```
主色调:
- 背景深: #0a0f1a (接近纯黑的深蓝)
- 背景中: #111827 (面板背景)
- 背景浅: #1f2937 (卡片背景)
- 边框: #2d3748 (分隔线)
- 主色: #3b82f6 (蓝色, 交互元素)
- 成功: #10b981 (绿色, 正常状态)
- 警告: #f59e0b (橙色, 警告状态)
- 危险: #ef4444 (红色, 错误状态)
- 文字主: #f9fafb (白色)
- 文字次: #9ca3af (灰色)
- 文字弱: #6b7280 (浅灰)
```

## 字体规范

```
Display: 'SF Pro Display', -apple-system, BlinkMacSystemFont, sans-serif
Body: 'SF Pro Text', -apple-system, BlinkMacSystemFont, sans-serif
Mono: 'SF Mono', 'Fira Code', monospace (数据展示)
```

## 布局优化

### 1. 侧边栏
- 增加品牌标识区高度
- 导航按钮增加active状态动画
- 底部信息区优化排版

### 2. 顶部栏
- 状态徽章增加脉冲动画
- 时间显示优化字体
- 用户信息区增加下拉菜单

### 3. 指标卡片
- 增加渐变背景
- 数值显示更大更醒目
- 增加趋势指示器

### 4. 视频墙
- 每个摄像头卡片增加实时状态指示
- 优化水印和标签显示
- 增加全屏查看功能

### 5. 机器人信息面板
- 重新设计布局为grid
- 电量显示增加进度条
- 步态显示增加图标

### 6. 时间线
- 优化时间轴样式
- 增加事件标记
- 优化统计数字显示

## 交互优化

1. 登录界面：增加动画效果，优化表单体验
2. 导航切换：平滑过渡动画
3. 数据刷新：增加loading状态
4. 错误处理：友好的错误提示

## 真实数据接入

所有API端点已实现，需要在前端完整接入：
- `/api/v1/status/latest` - 机器人状态
- `/api/v1/video` - 视频流状态
- `/api/v1/navigation/status` - 导航状态
- `/api/v1/work-orders` - 工单列表
- `/api/v1/inspection-points` - 巡检点
- `/api/v1/timeline` - 时间线数据
