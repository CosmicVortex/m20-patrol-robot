# M20 Pro 办公室阶段验收测试计划

## 前提条件

1. [ ] M20 Pro 在办公室静止站立
2. [ ] 已确认主机身份：NOS 10.21.31.106, GOS 10.21.31.104
3. [ ] 已完成办公室建图，active 地图已确认
4. [ ] 地图包已 pack 备份，记录 SHA-256
5. [ ] 现场负责人书面放行
6. [ ] 安全观察员在场
7. [ ] 急停按钮 accessible

## 测试项

### T1: 遥控器/APP 自主导航基线

- [ ] 切换至导航模式
- [ ] APP 标点：前门 → 工位A → 后门 → 返回
- [ ] 执行单点导航，观察：
  - [ ] 到点精度
  - [ ] 避障行为
  - [ ] 状态反馈
  - [ ] 异常停止

### T2: 实时状态显示

- [ ] 启动 GOS 仪表盘服务
- [ ] 接入真实状态（1002/6, 1002/4, 1002/5）
- [ ] 显示：
  - [ ] 运动状态
  - [ ] 步态
  - [ ] 电量
  - [ ] 定位状态
  - [ ] 急停状态
  - [ ] 异常列表

### T3: 前后相机视频

- [ ] 确认真实 RTSP URL
- [ ] 接入前相机流
- [ ] 接入后相机流
- [ ] Web 端切换显示正常
- [ ] 观察延迟和流畅度

### T4: Web 人工导航控制

- [ ] 点击"前往点位1"按钮
- [ ] 观察导航执行
- [ ] 点击"停止"按钮
- [ ] 确认导航取消
- [ ] 检查审计日志

### T5: 异常处理

- [ ] 模拟定位丢失
- [ ] 触发急停
- [ ] 低电量警告
- [ ] 断线重连

## 验收标准

- [ ] 所有测试项通过
- [ ] 异常停止可靠
- [ ] 审计日志完整
- [ ] 恢复机制正常
