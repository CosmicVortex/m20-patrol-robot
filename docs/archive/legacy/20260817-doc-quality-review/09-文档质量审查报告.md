- **实际代码**: `backend/app/api/extended_handlers.py` 第143-151行
  ```python
  class WorkOrdersUpdateHandler(BaseHandler):
      """PUT /api/v1/work-orders/<id> - Update work order."""
      def do_PUT(self) -> None:
          # Parse ID from path: /api/v1/work-orders/WO-2026-001
          parts = self.path.strip("/").split("/")
          if len(parts) != 3 or parts[2] == "":
              self.send_error_response(404, "Not found")
  ```
- **问题**: 处理器期望路径格式为 `/api/v1/work-orders/<id>`（3段），但文档写的是 `/api/v1/work-orders/`（末尾斜杠，无ID）。若按文档调用 `PUT /api/v1/work-orders/`，处理器会因 `parts[2] == ""` 而返回404。
