# M20 Pro 故障排查命令速查卡

## 快速诊断

```bash
# 一键深度诊断（首选）
cd ~/m20-patrol-robot
python3 deploy/scripts/diagnose-deep.py

# 服务状态
systemctl --user status m20-patrol-readonly.service

# 健康检查
curl -s http://127.0.0.1:8080/api/v1/health | python3 -m json.tool
```

## 常见症状

| 症状 | 命令 | 期望输出 |
|------|------|----------|
| NO_DATA | `curl /api/v1/health` | `{"healthy":false,...}` |
| 无数据 | `curl /api/v1/status` | `"source":"REAL"` + 实际数据 |
| 假数据 | `curl /api/v1/health` | `"source":"SIMULATED"` |

## 重启服务

```bash
systemctl --user restart m20-patrol-readonly.service
sleep 3
curl http://127.0.0.1:8080/api/v1/health
```

## 查看日志

```bash
# 实时日志
journalctl --user -u m20-patrol-readonly.service -f

# 关键日志
journalctl --user -u m20-patrol-readonly.service -n 50 --no-pager -l | grep -E "遥测|连接|心跳|ERROR"
```

## 网络测试

```bash
# Ping
ping -c 2 10.21.31.103

# TCP端口
timeout 5 bash -c 'echo | nc -v 10.21.31.103 30001'

# 扫描新IP
for i in {100..120}; do ping -c 1 -W 1 10.21.31.$i 2>/dev/null && echo "$i 在线"; done
```

## 更新IP配置

```bash
cd ~/m20-patrol-robot
sed -i 's/"10.21.31.103"/"新IP"/' deploy/readonly-manifest.json
bash deploy/scripts/deploy-readonly.sh --one-shot
```

## 完整诊断流程

```bash
1. python3 deploy/scripts/diagnose-deep.py 2>&1 | tee diag.txt
2. journalctl --user -u m20-patrol-readonly.service -n 50 > log.txt
3. curl http://127.0.0.1:8080/api/v1/health > health.json
4. 将以上文件内容发送给技术支持
```
