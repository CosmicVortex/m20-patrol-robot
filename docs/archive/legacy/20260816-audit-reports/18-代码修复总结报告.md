| `deploy/systemd/m20-patrol-realtime.service` | 14 | 同上 |

### 1. 导航状态缺少 loop_count 字段

**文件**: `backend/app/robot/status.py:229-237`

```python

return StatusResult("navigation_status", {
```

### 3. 连接状态显示不明确

**文件**: `docs/website/js/views/dashboard.js:149-169`

```javascript
// 修复前：仅区分 REAL/NO_DATA
if (source === 'REAL' && connected) { ... }
else if (source === 'NO_DATA') { ... }

// 修复后：区分 REAL/ERROR/STALE/NO_DATA
if (source === 'REAL' && connected) {
  badge.className = 'status-badge ok';
  badge.textContent = 'REAL / CONTROL ON';
} else if (source === 'REAL') {
  badge.className = 'status-badge warn';
  badge.textContent = 'REAL / RECONNECTING';
} else if (source === 'ERROR') {
  badge.className = 'status-badge blocked';
  badge.textContent = errorMsg ? `ERROR: ${errorMsg.slice(0, 20)}` : 'ERROR / FAILED';
} else if (source === 'STALE') {
  badge.className = 'status-badge warn';
  badge.textContent = 'STALE / TIMEOUT';
} else {
  badge.className = 'status-badge';
  badge.textContent = 'NO DATA / WAITING';
}
```
