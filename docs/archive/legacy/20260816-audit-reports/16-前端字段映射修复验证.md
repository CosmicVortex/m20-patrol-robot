## 修复详情

### 修复 F-01（补充）：received_at 字段存储

**问题**：
- dashboard.js 引用 `robot.received_at` 显示最后更新时间
- state-manager.js 未从 API 响应中提取并存储该字段

**修复位置**：`docs/website/js/state-manager.js`

**修改内容**：
```javascript
// updateTelemetry() 方法中添加
this.set('robot.connected', data.connected);
this.set('robot.source', data.source);
// 存储最后接收时间 ← 新增
this.set('robot.received_at', data.received_at || null);
```

**初始状态初始化**：
```javascript
robot: {
  // ... 其他字段
  received_at: null,
  raw_motion: null,
}
```

### 修复 F-04（补充）：步态默认值类型

**问题**：
- state-manager.js 初始默认值 `'flat'`（字符串）
- dashboard.js 映射表使用整数值 `4097, 4098, 12290, 12291`
- 类型不一致导致无数据时显示异常

**修复内容**：
```javascript
// 修改前
gait: 'flat',

// 修改后
gait: 0,  // 0 表示未知/无数据
```
