## 三、问题列表

### 🔴 严重问题

#### P0: 视频播放无法工作
- **位置:** `video/playback/` API
- **问题:** 后端返回空 URL，前端无 RTSP/WebSocket 播放器实现
- **影响:** 所有相机画面无法显示
- **根因:** `stream_manager.py` 中 camera 配置有 `rtsp_url`，但 `playback_url` 字段始终为空
- **修复建议:** 集成 WebSocket 视频代理或至少提供 placeholder 提示

### 🟠 高风险问题

#### H1: 默认管理员密码硬编码
- **位置:** `backend/app/server.py:188`, `backend/app/api/extended_handlers.py:665`
- **代码:** `password = "123456"`
- **问题:** 生产环境不应使用默认密码
- **修复建议:** 首次运行时强制修改密码，或使用环境变量 `M20_DEFAULT_ADMIN_PASSWORD`

#### H2: 网络地址硬编码
- **位置:** `stream_manager.py:54-57`, `device_handlers.py:59-61`, `gimbal/adapter.py:246`
- **问题:** 多处硬编码 `10.21.31.x` 地址，无法动态配置
- **影响:** 部署到其他网络时容易出错
- **修复建议:** 统一从 manifest.json 读取，或移除默认值

---

### 🟡 中风险问题

#### M1: emergency-btn 按钮不响应点击
- **位置:** `web/index.html:635`
- **问题:** 紧急停止按钮 `id="emergency-btn"` 无 onclick 事件绑定
- **现状:** 实际通过 `motion-estop-btn`（控制面板内）触发，该按钮工作正常
- **建议:** 移除或绑定 onclick，避免误导用户

#### M2: 缺少单元测试用例覆盖
- **位置:** `backend/tests/`
- **问题:** 当前 232 个测试均为框架自带测试，缺少业务逻辑测试
- **影响:** 协议编解码、安全联锁等核心逻辑未测试
- **建议:** 增加 `test_protocol.py`, `test_safety.py` 等专门测试文件

#### M3: pytest 需通过 venv 激活
- **位置:** 项目根目录
- **问题:** `pip` 不可用，需手动激活 venv 才能运行测试
- **建议:** 在 `deploy/run.sh` 或文档中明确说明

---

### 🟢 低风险问题

#### L1: 部分 JS 函数未绑定 DOM 事件
- **位置:** `web/js/app.js:141`
- **问题:** `showVideoConfigModal()` 函数定义但未找到绑定
- **影响:** 视频配置弹窗可能无法触发
- **修复:** 在 HTML 中添加触发按钮或绑定事件

#### L2: 数据报表视图图表功能未实现
- **位置:** `web/index.html:555`
- **问题:** 告警趋势图表显示"图表功能开发中..."
- **影响:** 报表视图功能不完整
- **修复:** 集成 Chart.js 或使用 SVG 实现

#### L3: 视频配置弹窗 ID 冲突
- **位置:** `web/index.html:591-604` vs `664-679`
- **问题:** 设置页面的 `rtsp-front` 等 ID 与弹窗中的同名 ID 冲突
- **影响:** 表单提交可能操作错误元素
- **修复:** 重命名弹窗中的 ID 前缀为 `modal-rtsp-`

#### L4: 前端字段映射一致性验证缺失
- **位置:** `web/js/state-manager.js`
- **问题:** 缺少类型检查和边界验证
- **建议:** 增加字段类型校验

#### L5: 日志级别配置未设置
- **位置:** `backend/app/server.py`
- **问题:** 使用默认日志配置，无轮转策略
