# 01 — 项目概览

## 目标

在 M20 Pro 机器狗上实现巡逻安防系统二次开发。程序部署于 GOS，通过 `basic_server` 协议与 AOS 通信，提供状态监控、视频回传和受控导航。

## 范围

### 纳入范围

- M20 Pro 本体前后相机视频回传
- 实时状态监控（运动状态、电量、异常、定位）
- Web 人工单点导航控制（授权后）

### 不纳入范围

- AOS/NOS 原厂服务修改
- 数尔安防云台/视频适配
- S10 平台适配

## 当前阶段

云端离线基线完成，等待 GOS 现场部署验证。

- 协议编解码、状态解析、导航报文构造、门禁系统全部离线验证通过
- 19 份官方文档已入库
- 169 个测试全部通过
- 三个代码阻塞项已全部修复
