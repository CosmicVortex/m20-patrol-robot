# 项目概览

## 目标

在 M20 Pro 机器狗上实现巡逻安防系统二次开发。程序部署于 GOS，通过 `basic_server` 协议与 AOS 通信，提供状态监控、视频回传和受控导航。

## 范围

**纳入**
- M20 Pro 本体前后相机视频回传
- 实时状态监控（运动状态、电量、异常、定位）
- Web 人工单点导航控制（授权后）

**不纳入**
- AOS/NOS 原厂服务修改
- 数尔安防云台/视频适配
- S10 平台适配

## 当前状态

云端离线基线完成，等待 GOS 现场部署验证。

- 协议编解码、状态解析、导航报文构造、门禁系统全部离线验证通过
- 180 个测试通过
- 部署脚本已适配 GOS 实机环境 (Ubuntu 20.04.6 LTS, aarch64, Python 3.8.10)

## 下一步

1. GOS/NOS/AOS 版本确认
2. basic_server 真实样本采集
3. RTSP 参数实测
4. 书面放行后完成 Web 单点导航控制
