# 项目概览

## 目标

在 M20 Pro 机器狗上实现巡逻安防系统的二次开发。程序部署于 GOS 主机，通过 `basic_server` 协议与 AOS 通信，提供状态监控、视频回传和受控导航。

## 范围

**纳入范围**
- M20 Pro 本体前后相机视频回传
- 实时状态监控（运动状态、电量、异常、定位）
- Web 人工单点导航控制（授权后）
- 数尔云台 SR-UPA810T609 控制与视频接入

**排除范围**
- AOS/NOS 原厂服务修改
- S10 平台适配（量产目标）

## 当前状态

云端离线基线完成，等待 GOS 现场部署验证。

- 协议编解码、状态解析、导航报文构造、门禁系统全部离线验证通过
- 180 个测试通过
- 部署脚本已适配 GOS 实机环境（Ubuntu 20.04.6 LTS, aarch64, Python 3.8.10）
