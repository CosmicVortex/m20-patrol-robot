## 问题关联分析

### 数据流图

```
用户部署
    │
    ▼
readonly-manifest.json
    │
    ├── read_only_mode=false → control_enabled=true → 需要evidence检查 ❌
    │
    ├── telemetry_tx_enabled=false → 不发送心跳 ❌
    │
    ▼
config.py: WebServiceConfig
    │
    ├── telemetry_tx_enabled=false → ConnectionConfig传入false ❌
    │
    ▼
server.py: 创建TelemetryAdapter
    │
    ├── ConnectionConfig(telemetry_tx_enabled=False)
    │
    ▼
telemetry.py: _run_loop()
    │
    ├── BasicServerConfig(transmit_enabled=False) ← 默认值 ❌
    │
    ▼
basic_client.py: send_read_only()
    │
    └── if not self.config.transmit_enabled:
            raise ClientStateError("transmit is disabled") ❌
```

### 最终结果

所有路径都被阻断，导致：
1. TCP连接可以建立
2. 心跳无法发送（transmit_enabled=False）
3. AOS在2秒后停止推送数据
4. 前端显示"NO DATA / WAITING"

## 修复后的数据流

```
readonly-manifest.json (read_only_mode=true, telemetry_tx_enabled=true)
    │
    ▼
config.py: WebServiceConfig (telemetry_tx_enabled=True)
    │
    ▼
server.py: ConnectionConfig (transmit_enabled=True)
    │
    ▼
telemetry.py: _run_loop()
    │
    ├── BasicServerConfig(transmit_enabled=True) ✓
    │
    ▼
basic_client.py: send_read_only()

AOS收到心跳 → 持续推送主动上报数据:
    ├── Type 1002 Cmd 6 (BasicStatus) ✅ 2Hz
    ├── Type 1002 Cmd 4 (MotionStatus) ✅ 10Hz
    ├── Type 1002 Cmd 5 (DeviceStatus) ✅ 2Hz
    └── Type 1002 Cmd 3 (ErrorList) ✅ 事件驱动
```
