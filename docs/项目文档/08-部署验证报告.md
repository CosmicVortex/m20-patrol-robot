#### 问题2: Python 3.8 兼容性失败 (8个文件)

以下文件使用了 `list[]`/`dict[]` 类型注解但未导入 `from __future__ import annotations`：

| 文件路径 | 问题类型 |
|----------|----------|
| `backend/app/robot/telemetry.py` | list[], dict[] |
| `backend/app/navigation/service.py` | list[] |
| `backend/app/motion/service.py` | list[] |
| `backend/app/websocket/upgrade.py` | list[] |
| `backend/app/protocol/frame.py` | list[] |
| `backend/app/utils/__init__.py` | list[] |
| `backend/app/utils/safety.py` | list[] |
| `backend/app/api/extended_handlers.py` | list[] |

**修复方法**: 在每个文件顶部添加：
```python
from __future__ import annotations
```

**注意**: UTC 导入已正确处理（使用 try/except fallback），无 f-string 日志使用，这两项检查通过。

#### 问题3: FFmpeg 二进制文件缺失

- **现象**: `deploy/offline/ffmpeg/ffmpeg-n7.1-latest-linuxarm64-gpl-7.1.tar.xz` 不存在
- **影响**: 视频流功能不可用（但服务仍可启动）
- **说明**: FFmpeg 需要单独获取并放置到此路径

  backend/app/robot/telemetry.py \
  backend/app/navigation/service.py \
