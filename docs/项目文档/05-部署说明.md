# 部署说明

## 1. 部署概述

本项目采用离线部署方案，所有依赖打包在部署镜像中，适合无互联网访问的现场环境。

**目标环境**:
- GOS主机: Ubuntu 20.04.6 LTS (aarch64)
- Python: 3.8.10（系统预装）
- FFmpeg: 7.1+（离线安装包）
- 网络: 10.21.31.0/24

## 2. 部署前准备

### 2.1 硬件要求

| 组件 | 要求 | 当前状态 |
|------|------|----------|
| GOS主机 | x86_64或aarch64 | ⚠️ 待确认 |
| 磁盘空间 | ≥1GB可用 | ⚠️ 待确认 |
| 内存 | ≥4GB RAM | ⚠️ 待确认 |

### 2.2 网络要求

GOS主机需访问：

| 目标 | 地址 | 端口 | 协议 | 用途 |
|------|------|------|------|------|
| AOS | 10.21.31.103 | 30001 | TCP | basic_server |
| AOS | 10.21.31.103 | 30000 | UDP | basic_server |
| AOS | 10.21.31.103 | 8554 | RTSP | 视频流 |
| 云台 | 10.21.31.108 | 80 | HTTP | 云台控制 |
| 云台 | 10.21.31.108 | 554 | RTSP | 热成像视频 |

### 2.3 工具准备

- SSH客户端（用于连接GOS）
- SCP或MobaXterm（用于传输文件）
- 浏览器（用于访问Web界面）

## 3. 离线部署流程

### 3.1 构建部署包

在联网开发机上执行：

```bash
cd /opt/data/m20-patrol-robot
bash deploy/scripts/build-offline-deploy-package.sh
```

生成文件: `m20-patrol-robot.zip`

### 3.2 传输到GOS

```bash
# 方式一: SCP传输
scp m20-patrol-robot.zip user@10.21.31.104:/home/user/

# 方式二: MobaXterm SFTP拖拽
# 打开MobaXterm → SFTP → 拖拽文件到/home/user/
```

### 3.3 SSH登录并部署

```bash
# 登录GOS
ssh user@10.21.31.104

# 解压部署包
cd ~
unzip -q m20-patrol-robot.zip -d ~/m20-patrol-robot

# 进入项目目录
cd ~/m20-patrol-robot
```

### 3.4 FFmpeg安装（如未安装）

```bash
# 检查是否已安装
command -v ffmpeg || echo "未安装"

# 如未安装，执行离线安装
cd ~/m20-patrol-robot/deploy/offline/ffmpeg
bash install-ffmpeg-offline.sh
```

### 3.5 运行部署脚本

```bash
# 一键部署（推荐）
bash deploy/scripts/deploy-readonly.sh --one-shot

# 或分步执行
bash deploy/scripts/deploy-readonly.sh --check    # 预检查
bash deploy/scripts/deploy-readonly.sh --install  # 安装
bash deploy/scripts/deploy-readonly.sh --start    # 启动
```

## 5. systemd服务管理

### 5.1 服务名称

```
m20-patrol-readonly.service
```

### 5.2 常用命令

```bash
# 启动服务
systemctl --user start m20-patrol-readonly

# 停止服务
systemctl --user stop m20-patrol-readonly

# 重启服务
systemctl --user restart m20-patrol-readonly

# 查看状态
systemctl --user status m20-patrol-readonly

# 查看日志
journalctl --user -u m20-patrol-readonly -f

# 设置开机自启
systemctl --user enable m20-patrol-readonly
```

### 5.3 服务文件位置

```
~/.config/systemd/user/m20-patrol-readonly.service
```

## 6. 回滚方案

### 6.1 备份当前部署

```bash
# 备份配置
cp -r ~/m20-patrol-robot ~/m20-patrol-robot.backup

# 备份密码配置
cp -r ~/.config/m20-patrol ~/.config/m20-patrol.backup
```

### 6.2 回滚步骤

```bash
# 停止服务
systemctl --user stop m20-patrol-readonly

# 恢复备份
rm -rf ~/m20-patrol-robot
mv ~/m20-patrol-robot.backup ~/m20-patrol-robot

# 恢复配置
rm -rf ~/.config/m20-patrol
mv ~/.config/m20-patrol.backup ~/.config/m20-patrol

# 重启服务
systemctl --user start m20-patrol-readonly
```

### 6.3 快速回滚脚本

```bash
bash deploy/scripts/rollback-gos.sh
```

## 8. 故障排查

### 8.1 服务无法启动

```bash
# 查看详细日志
journalctl --user -u m20-patrol-readonly -n 100

# 检查端口占用
ss -tlnp | grep 8080

# 检查Python路径
which python3
python3 --version
```

### 8.2 无法连接AOS

```bash
# 检查网络
ping 10.21.31.103

# 检查端口
nc -zv 10.21.31.103 30001

# 检查防火墙
sudo iptables -L -n | grep 30001
```

### 8.3 FFmpeg问题

```bash
# 检查安装
ffmpeg -version

# 检查RTSP支持
ffmpeg -protocols 2>/dev/null | grep rtsp

# 重新安装
bash deploy/offline/ffmpeg/install-ffmpeg-offline.sh
```

## 9. 注意事项

1. **密码安全**: 部署后务必修改默认密码123456
2. **网络隔离**: 确保GOS与AOS/云台网络互通
3. **FFmpeg版本**: 必须使用7.1+版本，支持RTSP over TCP
4. **离线环境**: 所有操作必须在无互联网环境下完成
5. **品牌保留**: 不得修改"中升之星奔驰"等品牌名称
