## 五、部署问题与解决方案

### 5.1 FFmpeg RTSP 支持不足（阻塞项）

**问题**：系统 ffmpeg 4.2.7 不支持 RTSP 协议，导致视频流代理功能无法工作。

**解决方案**：安装离线 FFmpeg 7.1 包。

**执行命令（在 GOS 上执行）**：
```bash
cd ~/m20-patrol-robot
bash deploy/offline/ffmpeg/install-ffmpeg-offline.sh
ffmpeg -version | head -1
```

### 5.2 SHA-256 校验失败

**问题**：SHA 文件包含云端绝对路径 `/opt/data/m20-patrol-robot/deploy/...`，GOS 上路径不同。

**解决方案**：手动校验或使用绝对路径重新生成。

**执行命令（在 GOS 上执行）**：
```bash
cd ~
sha256sum m20-patrol-robot-offline-deploy.tar.gz
# 与云端 SHA 对比：be38d01ac704d866c6a66c88476ad7fea9d2003606937063454e8040f0c059da
```

### 5.3 旧部署包残留

**GOS 目录中的旧文件**：
```
/home/user/
├── m20-patrol-robot-deploy.tar.gz    ← 旧包（已解压）
├── m20-patrol-robot/                  ← 旧部署目录
├── m20-patrol-robot-offline-deploy.tar.gz  ← 新包
├── m20-patrol-robot-offline-deploy.tar.gz.sha256
└── ...
```

**建议清理**（安装完 FFmpeg 并验证后）：
```bash
rm -f m20-patrol-robot-deploy.tar.gz
# rm -rf m20-patrol-robot  # 确认新部署正常后再删除
```
