## 2. 核心模块说明

### 2.1 protocol/frame.py - APDU帧编解码

**职责**: 实现basic_server协议的16字节固定头部解析

**关键结构**:
```python
@dataclass(frozen=True)
class FrameLayout:
    sync_word: bytes        # b'\xeb\x91\xeb\x90' (4字节同步头)
    length_offset: int      # 16字节头部偏移4
    length_size: int        # 2字节小端序
    message_id_offset: int  # 偏移6
    message_id_size: int    # 2字节
    flags_offset: int       # 偏移8 (ASDU格式: 0x00=XML, 0x01=JSON)
    header_size: int        # 16字节固定

@dataclass(frozen=True)
class Frame:
    message_id: int    # 请求/响应关联ID
    payload: bytes     # ASDU载荷(JSON/XML)
    flags: int         # 格式标志
```

### 2.2 robot/basic_client.py - basic_server客户端

**职责**: 维护TCP连接，发送心跳，接收状态数据

**关键配置**:
```python
@dataclass
class BasicServerConfig:
    host: str                    # AOS地址 (10.21.31.103)
    tcp_port: int = 30001        # TCP端口
    control_enabled: bool = False # 是否允许控制
    stale_after_seconds: float = 3.0  # 数据过期阈值
```

### 2.3 robot/telemetry.py - 遥测适配器

**职责**: 维护与AOS的长连接，持续接收状态数据

**数据缓存**:
```python
@dataclass
class StatusSnapshot:
    source: str            # "REAL" 或 "SIMULATED"
    connected: bool        # TCP连接状态
    received_at: str       # 最后接收时间
    age_ms: int            # 数据年龄(毫秒)
    basic: dict            # 基础状态
    motion: dict           # 运动状态
    device: dict           # 设备状态
    errors: list           # 错误列表
    nav_status: dict       # 导航状态
    position: dict         # 位置信息
    perception: dict       # 感知状态
```

### 2.7 gimbal/adapter.py - 数尔云台适配

**职责**: 实现数尔WEB协议V1.0

**关键方法**:
- `login()`: HTTP登录，获取Session
- `get_state()`: 获取云台状态 (RPY角度)
- `set_angle(yaw, pitch, roll)`: RPY角度控制
- `move_direction(direction, speed)`: 方向控制（up/down/left/right）
- `zoom_to(level)`: 变倍控制（1-10）
- `scan(ranges)`: 网络扫描云台设备
- `set_laser_ranging(enable)`: 激光测距开关

### 2.8 运动状态与步态定义（来自官方文档）

**运动状态值**（`mountain_m20_m20_pro/motion-control.md` V1.0.0）:

| 十进制值 | 十六进制 | 名称 | 说明 |
|----------|----------|------|------|
| 0 | 0x00 | 空闲 | 空闲状态，无动作，等待指令 |
| 1 | 0x01 | 站立 | 临时过渡状态，会自动跳转到RL控制状态 |
| 2 | 0x02 | 软急停 | 关节断电，最高优先级，任意状态下均可触发 |
| 3 | 0x03 | 开机阻尼 | 开机后自动进入的阻尼状态 |
| 4 | 0x04 | 趴下 | 安全趴下状态 |
| 17 | 0x11 | RL控制 | 强化学习控制模式，唯一可执行移动和步态切换的状态 |

> **关键：** 站立（1）是一个临时过渡状态，不是可以持续保持的状态。机器人会自动从站立（1）进入RL控制（17），此时才能执行移动控制和步态切换。

**步态值**（`mountain_m20_m20_pro/motion-control.md` V1.0.0）:

| 十进制值 | 十六进制 | 名称 | 运动模式 | 适用场景 |
|----------|----------|------|----------|----------|
| 4097 | 0x1001 | 基础 | 标准 | 室内平坦地面，手动遥控 |
| 4099 | 0x1003 | 楼梯 | 标准 | 台阶/路沿，手动遥控 |
| 12290 | 0x3002 | 平地 | 敏捷 | 自主导航 + 平地行走 |
| 12291 | 0x3003 | 楼梯 | 敏捷 | 自主导航 + 台阶跨越 |

> **敏捷运动模式**下的步态速度响应性能较好，适用于导航等自主算法开发。每次起立后或切换使用模式（常规/辅助/导航）时，步态会自动重置为基础步态（0x1001）。
