## 二、环境要求

**GOS主机要求**:
- 系统: Ubuntu 20.04.6 LTS (aarch64)
- Python: 3.8.10（系统预装）
- systemd: 245+
- 磁盘空间: ≥50MB
- 网络: 可访问 AOS (10.21.31.103) 和 NOS (10.21.31.106)

**禁止项**:
- ❌ 禁止使用root用户部署
- ❌ 禁止使用Python虚拟环境（GOS环境venv不可用）
- ❌ 禁止sudo操作

### 步骤1：传输部署包到GOS

或使用 MobaXterm 文件浏览器拖拽上传。

### 步骤2：登录GOS并解压


### 步骤3：设置密码


## 四、故障排查

### 4.1 服务未启动

```bash
# 查看服务状态
systemctl --user status m20-patrol-readonly

# 查看完整日志
journalctl --user -u m20-patrol-readonly -f
```

**常见问题**:
- Python模块导入失败 → 检查 `PYTHONPATH` 环境变量
- TCP连接失败 → 确认 AOS IP 和端口正确
- 端口冲突 → `netstat -tlnp | grep 8080`

---

### 4.2 遥测无数据

```bash
# 检查遥测状态
curl http://127.0.0.1:8080/api/v1/status/latest

# 查看连接状态
curl http://127.0.0.1:8080/api/v1/health
```

**判定标准**:
```
source=REAL          # 真实数据源（非SIMULATED）
connected=true       # TCP已连接
valid_frames>0       # 已解析协议帧
age_ms < 3000        # 数据新鲜度<3秒
```

---

### 4.3 端口冲突

```bash
# 查找占用端口的进程
netstat -tlnp | grep 8080

# 停止冲突服务
systemctl --user stop m20-patrol-readonly
```

---

### 4.4 回滚部署

```bash
# 停止服务
bash deploy/scripts/deploy-readonly.sh --stop

# 清理部署目录
rm -rf ~/.local/share/m20-patrol-robot

# 清理systemd服务
systemctl --user disable m20-patrol-readonly
systemctl --user daemon-reload
```

## 六、安全注意事项

1. **控制权限默认关闭**
   - `control_enabled=false`（只读模式）
   - 导航控制需书面放行

2. **密码安全**
   - 密码文件权限: `600`
   - 禁止提交密码到Git仓库

3. **审计日志**
   - 所有控制操作记录到 `journalctl`
   - 日志保留30天

4. **系统隔离**
   - `PrivateTmp=true`
   - `ProtectSystem=strict`
   - `NoNewPrivileges=true`
