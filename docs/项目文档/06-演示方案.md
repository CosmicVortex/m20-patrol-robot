# 演示方案

## 一、演示概述

**演示场景**: 奔驰4S店安保巡逻系统  
**演示机型**: M20 Pro  
**演示时长**: 15-20 分钟  
**演示目标**: 在现场门禁通过后展示状态监控；视频、云台和导航能力仅在各自验收项通过后加入演示

---

## 二、演示流程

### 阶段 1：系统登录与状态确认（3分钟）

1. **启动服务**
   ```bash
   # 在 GOS 上
   systemctl --user status m20-patrol-readonly.service
   # 确保服务运行中
   ```

2. **浏览器访问**
   - 打开浏览器访问: `http://10.21.31.104:8080/`
   - 登录账号: `admin` / `123456`

3. **状态确认**
   - 检查仪表盘显示 `source=REAL`
   - 确认 `connected=true`
   - 查看实时状态数据（电量、姿态、位置）

### 阶段 2：视频回传验证（条件项）

1. **本体视频**
   - 切换前/后相机视频源
   - 展示实时视频画面

2. **云台视频**
   - 连接数尔云台: `POST /api/v1/gimbal/connect`
   - 展示可见光视频
   - 切换热成像视频

3. **视频对比**
   - 同时展示本体相机与云台相机画面
   - 说明热成像在夜巡中的应用

### 阶段 3：云台验证（条件项）

1. **角度控制**
   - 调整云台 yaw/pitch 角度
   - 展示实时角度反馈

2. **变倍控制**
   - 使用变倍按钮放大画面
   - 展示光学变倍效果

3. **状态查询**
   - 查看云台设备状态（CPU、内存）
   - 查看激光测距数据（如已实现）

### 阶段 4：导航控制演示（需 Web 授权）

**前置条件**：`control_enabled=true` 且 `read_only_mode=false`

1. **授权控制**
   - 点击"授权控制"按钮（需 admin 角色）
   - 系统记录授权日志

2. **设置巡检点**
   - 在地图上点击设置巡检点
   - 或输入坐标: `pos_x=1.5, pos_y=2.0`

3. **执行导航**
   - 点击"发送导航"按钮
   - 观察机器狗运动
   - 查看导航状态: 导航预处理 → 导航中 → 导航完成

4. **取消导航**
   - 点击"取消导航"按钮
   - 确认机器狗停止

5. **紧急停止**
   - 点击"紧急停止"按钮（需 admin 角色）
   - 机器狗立即停止所有运动

> **安全警告**：执行控制操作前必须确认场地隔离、物理急停可用、现场观察员就位。

### 阶段 5：异常告警演示（2分钟）

1. **异常数据说明**
   - 查看历史异常记录或离线测试夹具
   - 不在演示中主动触发软急停

2. **告警展示**
   - 查看异常列表
   - 展示错误码含义

## 五、应急预案

### 5.1 视频流无法显示

```bash
# 检查 RTSP 地址是否正确
ffprobe -v error rtsp://10.21.31.103:8554/video1

# 地址不一致时停止演示并记录现场值，不直接修改受控清单
```

### 5.2 导航控制启用（需 Web 授权）

```bash
# 1. 确认控制模式已启用
curl -s http://10.21.31.104:8080/api/v1/health | jq .

# 2. 管理员登录并获取 token
curl -X POST http://10.21.31.104:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username": "admin", "password": "123456"}'

# 3. 授权导航控制
curl -X POST http://10.21.31.104:8080/api/v1/navigation/authorize \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"operator": "demo", "note": "演示授权"}'

# 4. 执行导航
curl -X POST http://10.21.31.104:8080/api/v1/navigation/tasks \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"action": "send", "pos_x": 1.5, "pos_y": 2.0}'
```

### 5.3 服务异常重启

```bash
# 重启服务
systemctl --user restart m20-patrol-readonly.service

# 查看日志
journalctl --user -u m20-patrol-readonly.service -f
```
