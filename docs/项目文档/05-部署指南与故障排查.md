# 部署说明

## 1. 部署概述

本项目采用离线部署方案，所有依赖打包在部署镜像中，适合无互联网访问的现场环境。

**目标环境**:
- GOS主机: Ubuntu 20.04.6 LTS (aarch64)
- Python: 3.8.10（系统预装）
- FFmpeg: 7.1+（离线安装包）
- 网络: 10.21.31.0/24

## 2. 部署前准备

### 2.1 硬件要求

| 组件 | 要求 | 当前状态 |
|------|------|----------|
| GOS主机 | aarch64 | ✅ 已确认 |
| 磁盘空间 | ≥1GB可用 | 🟡 待现场验证 |
| 内存 | ≥4GB RAM | 🟡 待现场验证 |

GOS主机需访问：

| 目标 | 地址 | 端口 | 协议 | 用途 |
|------|------|------|------|------|
| AOS | 10.21.31.103 | 30001 | TCP | basic_server |
| AOS | 10.21.31.103 | 30000 | UDP | basic_server |
| AOS | 10.21.31.103 | 8554 | RTSP | 视频流 |
| 云台 | 10.21.31.108 | 80 | HTTP | 云台控制 |

- SCP或MobaXterm（用于传输文件）
- 浏览器（用于访问Web界面）

## 3. 离线部署流程

### 3.1 构建部署包

在联网开发机上执行：

```bash
cd /opt/data/m20-patrol-robot
bash deploy/scripts/build-offline-deploy-package.sh
```

生成文件: `m20-patrol-robot.zip`

### 3.2 传输到GOS

```bash
# 方式一: SCP传输
scp m20-patrol-robot.zip user@10.21.31.104:/home/user/

# 方式二: MobaXterm SFTP拖拽
# 打开MobaXterm → SFTP → 拖拽文件到/home/user/
```

### 3.3 SSH登录并部署

```bash
# 登录GOS
ssh user@10.21.31.104

# 解压部署包
cd ~
unzip -q m20-patrol-robot.zip -d ~/m20-patrol-robot

# 进入项目目录
cd ~/m20-patrol-robot
```

### 3.4 FFmpeg安装（如未安装）

```bash
# 检查是否已安装
command -v ffmpeg || echo "未安装"

# 如未安装，执行离线安装
cd ~/m20-patrol-robot/deploy/offline/ffmpeg
bash install-ffmpeg-offline.sh
```

### 3.5 运行部署脚本

```bash
# 一键部署（推荐）
bash deploy/scripts/deploy-readonly.sh --one-shot

# 或分步执行
bash deploy/scripts/deploy-readonly.sh --check    # 预检查
bash deploy/scripts/deploy-readonly.sh --install  # 安装
bash deploy/scripts/deploy-readonly.sh --start    # 启动
```

### 4.2 manifest字段说明

| 字段 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| manifest_version | string | 清单版本 | "1.0.0" |
| project | string | 项目名称 | "m20-patrol-robot" |
| runtime_mode | string | 运行时模式 | "realtime_readonly" |
| read_only_mode | bool | 只读模式开关 | true |
| control_enabled | bool | 控制权限开关 | false |
| telemetry_rx_enabled | bool | 接收遥测启用 | true |
| telemetry_tx_enabled | bool | 发送心跳启用 | true |

| static_root | string | 静态文件根目录 | "docs/website" |
| stale_after_seconds | int | 数据过期时间(秒) | 3 |
| auth_enabled | bool | 认证启用 | false |
| allow_anonymous | bool | 允许匿名访问 | true |
| targets.gos_host | string | GOS主机地址 | 10.21.31.104 |
| targets.aos_host | string | AOS主机地址 | 10.21.31.103 |
| targets.nos_host | string | NOS主机地址 | 10.21.31.106 |
| targets.gimbal_host | string | 云台地址 | 10.21.31.108 |

| ports.aos_tcp | int | AOS TCP端口 | 30001 |
| ports.aos_udp | int | AOS UDP端口 | 30000 |
| ports.rtsp | int | RTSP端口 | 8554 |
| ports.web | int | Web端口 | 8080 |
| target_source | string | 地址来源标识 | PROJECT_OWNER_CONFIRMED_FIXED_FACT |

## 7. 故障排查

### 7.1 服务无法启动

```bash
# 查看详细日志
journalctl --user -u m20-patrol-readonly -n 100

# 检查端口占用
ss -tlnp | grep 8080

# 检查Python路径
which python3
python3 --version
```

### 7.2 无法连接AOS

```bash
# 检查网络
ping 10.21.31.103

# 检查端口
nc -zv 10.21.31.103 30001

# 检查防火墙
sudo iptables -L -n | grep 30001
```

### 7.3 FFmpeg问题

```bash
# 检查安装
ffmpeg -version

# 检查RTSP支持
ffmpeg -protocols 2>/dev/null | grep rtsp

# 重新安装
bash deploy/offline/ffmpeg/install-ffmpeg-offline.sh
```

## 8. 注意事项

1. **密码安全**: 部署后务必修改默认密码
2. **网络隔离**: 确保GOS与AOS/云台网络互通
3. **FFmpeg版本**: 必须使用7.1+版本，支持RTSP over TCP
4. **离线环境**: 所有操作必须在无互联网环境下完成
5. **品牌保留**: 不得修改"中升之星奔驰"等品牌名称

## 9. 常见问题（FAQ）

### Q1: 服务启动失败，提示端口被占用？

```bash
# 查看占用端口的进程
ss -tlnp | grep 8080

# 杀掉占用进程
sudo kill -9 <PID>

# 或修改 manifest.json 中的端口配置
```

### Q2: Web界面显示"NO_DATA"？

**可能原因**:
- TCP 30001端口不通（basic_server未连接）
- 网络配置错误

**排查步骤**:
```bash
# 检查AOS TCP连接
nc -zv 10.21.31.103 30001

# 检查日志
journalctl --user -u m20-patrol-readonly -n 50
```

### Q3: 视频画面无法播放？

**检查清单**:
- FFmpeg版本 ≥ 7.1（支持RTSP over TCP）
- RTSP地址已正确配置
- 防火墙允许8554端口

```bash
# 验证FFmpeg RTSP支持
ffmpeg -protocols 2>/dev/null | grep rtsp
```

### Q4: 运动控制无响应？

**前提条件**:
1. 确认 `read_only_mode: false` 且 `control_enabled: true`
2. 在Web界面点击"授权运动控制"按钮
3. 确认机器狗处于站立状态（state=1）

### Q5: 导航任务下发失败？

**常见原因**:
- 地图未构建或地图ID错误
- 未授权导航控制
- 机器狗定位状态异常

**检查方法**:
```bash
curl http://localhost:8080/api/v1/navigation/status
```

### Q6: 如何查看系统运行日志？

```bash
# 实时查看日志
journalctl --user -u m20-patrol-readonly.service -f

# 查看最近100行
journalctl --user -u m20-patrol-readonly.service -n 100
```

### Q7: 默认密码是什么？

默认用户名: `admin`
默认密码: `123456`（首次登录后必须修改）

云台密码通过配置文件 `~/.config/m20-patrol/passwords.env` 设置。
