# 部署说明

## 1. 部署概述

本项目采用离线部署方案，所有依赖打包在部署镜像中，适合无互联网访问的现场环境。

**目标环境**:
- GOS主机: Ubuntu 20.04.6 LTS (aarch64)
- Python: 3.8.10（系统预装）
- FFmpeg: 7.1+（离线安装包）
- 网络: 10.21.31.0/24

## 2. 部署前准备

### 2.1 硬件要求

| 组件 | 要求 | 当前状态 |
|------|------|----------|
| GOS主机 | aarch64 | ✅ 已确认 |
| 磁盘空间 | ≥1GB可用 | 🟡 待现场验证 |
| 内存 | ≥4GB RAM | 🟡 待现场验证 |

### 2.2 网络要求

GOS主机需访问：

| 目标 | 地址 | 端口 | 协议 | 用途 |
|------|------|------|------|------|
| AOS | 10.21.31.103 | 30001 | TCP | basic_server |
| AOS | 10.21.31.103 | 30000 | UDP | basic_server |
| AOS | 10.21.31.103 | 8554 | RTSP | 视频流 |
| 云台 | 10.21.31.108 | 80 | HTTP | 云台控制 |
| 云台 | 10.21.31.108 | 554 | RTSP | 热成像视频 |

- SSH客户端（用于连接GOS）
- SCP或MobaXterm（用于传输文件）
- 浏览器（用于访问Web界面）

## 3. 离线部署流程

### 3.1 构建部署包

在联网开发机上执行：

```bash
cd /opt/data/m20-patrol-robot
bash deploy/scripts/build-offline-deploy-package.sh
```

生成文件: `m20-patrol-robot.zip`

### 3.2 传输到GOS

```bash
# 方式一: SCP传输
scp m20-patrol-robot.zip user@10.21.31.104:/home/user/

# 方式二: MobaXterm SFTP拖拽
# 打开MobaXterm → SFTP → 拖拽文件到/home/user/
```

### 3.3 SSH登录并部署

```bash
# 登录GOS
ssh user@10.21.31.104

# 解压部署包
cd ~
unzip -q m20-patrol-robot.zip -d ~/m20-patrol-robot

# 进入项目目录
cd ~/m20-patrol-robot
```

### 3.4 FFmpeg安装（如未安装）

⚠️ **重要说明**：由于FFmpeg官方已不再提供arm64预编译包，必须在GOS主机上编译安装。

```bash
# 检查是否已安装
command -v ffmpeg || echo "未安装"

# 如未安装，执行编译安装（推荐）
cd ~/m20-patrol-robot/deploy/offline/ffmpeg
bash compile-ffmpeg-arm64.sh

# 编译完成后，运行离线安装脚本
bash install-ffmpeg-offline.sh
```

**编译脚本功能**：
1. 自动安装编译依赖（build-essential, nasm, yasm等）
2. 克隆FFmpeg 7.1源码
3. 配置交叉编译（启用RTSP、H.264、H.265等）
4. 编译并打包为 `ffmpeg-n7.1-latest-linuxarm64-gpl-7.1.tar.xz`

**备选方案**（apt快速安装）：
```bash
# 在GOS主机上
sudo apt-get update
sudo apt-get install -y ffmpeg

# 验证版本（需要≥7.1）
ffmpeg -version | head -1

# 创建符号链接
mkdir -p ~/m20-patrol-robot/deploy/offline/ffmpeg
ln -sf /usr/bin/ffmpeg ~/m20-patrol-robot/deploy/offline/ffmpeg/
ln -sf /usr/bin/ffprobe ~/m20-patrol-robot/deploy/offline/ffmpeg/
```

### 3.5 运行部署脚本

```bash
# 一键部署（推荐）
bash deploy/scripts/deploy-readonly.sh --one-shot

# 或分步执行
bash deploy/scripts/deploy-readonly.sh --check    # 预检查
bash deploy/scripts/deploy-readonly.sh --install  # 安装
bash deploy/scripts/deploy-readonly.sh --start    # 启动
```

## 8. FFmpeg编译安装说明

由于FFmpeg官方（ffmpeg.org）和第三方构建站点（gyan.dev、johnvansickle.com）均已停止提供arm64静态构建包，本项目采用源码编译方式满足GOS主机的FFmpeg需求。

### 8.1 编译脚本说明

**脚本位置**: `deploy/offline/ffmpeg/compile-ffmpeg-arm64.sh`

**自动执行步骤**：
1. 安装编译依赖（build-essential, git, autoconf, automake, libtool, nasm, yasm等）
2. 克隆FFmpeg 7.1源码（`git clone --branch n7.1`）
3. 配置交叉编译参数：
   - `--arch=arm64 --target-os=linux`
   - `--enable-gpl --enable-nonfree`（GPL许可）
   - `--enable-libx264 --enable-libx265`（H.264/H.265编码器）
   - `--enable-libmp3lame --enable-libopus --enable-libvorbis --enable-libvpx`（音频/视频编码）
   - `--enable-static --disable-shared`（静态链接）
   - `--disable-doc --disable-programs`（仅编译核心库）
4. 并行编译（`make -j$(nproc)`）
5. 打包为 `ffmpeg-n7.1-latest-linuxarm64-gpl-7.1.tar.xz`
6. 计算SHA256校验和

**预计耗时**：5-15分钟（取决于GOS主机性能）

### 8.2 安装脚本说明

**脚本位置**: `deploy/offline/ffmpeg/install-ffmpeg-offline.sh`

**执行步骤**：
1. 验证架构（aarch64/arm64）
2. 校验压缩包完整性（SHA256）
3. 解压到临时目录
4. 提取bin目录内容
5. 安装到 `~/.local/opt/m20-ffmpeg/7.1/current/`
6. 创建符号链接到 `~/.local/bin/`
7. 验证安装结果

**安装路径**：
```
~/.local/opt/m20-ffmpeg/7.1/current/bin/ffmpeg
~/.local/opt/m20-ffmpeg/7.1/current/bin/ffprobe
~/.local/bin/ffmpeg → ~/.local/opt/m20-ffmpeg/7.1/current/bin/ffmpeg
~/.local/bin/ffprobe → ~/.local/opt/m20-ffmpeg/7.1/current/bin/ffprobe
```

### 8.3 环境变量配置

确保systemd服务能找到FFmpeg：

### 8.5 故障排查

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 架构不匹配 | 非arm64环境 | 在GOS主机（aarch64）上执行 |
| 编译依赖缺失 | apt源未更新 | `sudo apt-get update && sudo apt-get install -y <包名>` |
| 磁盘空间不足 | /tmp或/home空间不够 | 清理空间或指定其他编译目录 |
| 网络超时 | 无法访问git.ffmpeg.org | 使用镜像源或手动下载源码 |
| SHA256校验失败 | 压缩包损坏 | 重新运行编译脚本 |

## 9. 注意事项

1. **密码安全**: 部署后务必修改默认密码
2. **网络隔离**: 确保GOS与AOS/云台网络互通
3. **FFmpeg版本**: 必须使用7.1+版本，支持RTSP over TCP
4. **离线环境**: 所有操作必须在无互联网环境下完成
5. **品牌保留**: 不得修改"中升之星奔驰"等品牌名称

## 10. 常见问题（FAQ）

### Q1: 服务启动失败，提示端口被占用？

```bash
# 查看占用端口的进程
ss -tlnp | grep 8080

# 杀掉占用进程
sudo kill -9 <PID>

# 或修改 manifest.json 中的端口配置
```

### Q2: Web界面显示"NO_DATA"？

**可能原因**:
- TCP 30001端口不通（basic_server未连接）
- 网络配置错误

**排查步骤**:
```bash
# 检查AOS TCP连接
nc -zv 10.21.31.103 30001

# 检查日志
journalctl --user -u m20-patrol-readonly -n 50
```

### Q3: 视频画面无法播放？

**检查清单**:
- FFmpeg版本 ≥ 7.1（支持RTSP over TCP）
- RTSP地址已正确配置
- 防火墙允许8554端口

```bash
# 验证FFmpeg RTSP支持
ffmpeg -protocols 2>/dev/null | grep rtsp
```

### Q4: 运动控制无响应？

**前提条件**:
1. 确认 `read_only_mode: false` 且 `control_enabled: true`
2. 在Web界面点击"授权运动控制"按钮
3. 确认机器狗处于站立状态（state=1）

### Q5: 导航任务下发失败？

**常见原因**:
- 地图未构建或地图ID错误
- 未授权导航控制
- 机器狗定位状态异常

**检查方法**:
```bash
curl http://localhost:8080/api/v1/navigation/status
```

### Q6: 如何查看系统运行日志？

```bash
# 实时查看日志
journalctl --user -u m20-patrol-readonly.service -f

# 查看最近100行
journalctl --user -u m20-patrol-readonly.service -n 100
```

### Q7: 默认密码是什么？

默认用户名: `admin`
默认密码: `123456`（首次登录后必须修改）

云台密码通过配置文件 `~/.config/m20-patrol/passwords.env` 设置。

### Q8: FFmpeg如何安装？

由于FFmpeg官方已停止提供arm64预编译包，**必须在GOS主机上编译安装**。

**方案一：源码编译（推荐）**
