## 快速开始

1. 阅读 `01-项目概述与需求.md` 了解项目背景
2. 阅读 `02-系统架构设计.md` 理解整体架构
3. 阅读 `05-部署指南.md` 进行部署
4. 遇到问题查阅 `06-故障排查手册.md`

## 维护规范

| 规则 | 说明 |
|------|------|
| 单份权威文档 | 同类主题只保留一份最新文档 |
| 版本号管理 | 文档版本与项目版本同步 |
| 变更日志 | 重大变更记录在 `07-changes.md` |
| 归档机制 | 过程性报告归档至 `archive/legacy/` |
| 去AI化 | 删除"本文"、"值得关注"等AI表达 |
