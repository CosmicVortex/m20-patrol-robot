## 文档结构

```
docs/
├── 项目文档/                    ← 项目级技术文档（编号顺序）
│   ├── 00-文档索引.md           ← 导航入口
│   ├── 01-项目概述与需求.md     ← 项目背景、目标、验收标准
│   ├── 02-系统架构与协议.md     ← 整体架构、网络拓扑、协议栈
│   ├── 03-核心模块实现.md       ← 模块实现细节、数据结构、运动状态定义
│   ├── 04-部署与运维指南.md     ← 部署流程、环境配置、回滚方案
│   ├── 05-故障排查手册.md       ← 常见问题、诊断命令、解决方案
│   ├── 06-API参考.md            ← REST接口、请求响应格式
│   ├── 07-协议对齐说明.md       ← V1.2.1对照、字段映射、差异记录
│   └── 08-功能演示方案.md       ← 演示流程、测试用例、注意事项
├── 官方文档/                   ← 厂商手册（只读）
│   ├── 机器狗本体/            ← 19个核心协议文档
│   └── 上装设备/              ← 3个云台文档
└── archive/                   ← 归档（离线部署包等）
```
