# 模块说明

## 架构概览

系统采用分层架构：协议层解析 basic_server 报文 → 机器人层管理连接和遥测 → 业务层实现导航/运动/云台控制 → API层提供HTTP接口 → 前端展示实时监控数据。

## 核心模块

### protocol/ — 协议层

负责APDU帧的编解码和粘包处理。

| 文件 | 功能 |
|------|------|
| frame.py | 16字节帧头解析，同步字EB91EB90，支持JSON/XML格式 |
| messages.py | PatrolMessage数据模型，message_type/command/items字段 |

**关键常量**：
- 心跳: Type=100, Cmd=100
- 状态上报: Type=1002, Cmd=3/4/5/6
- 导航请求: Type=1003, Cmd=1
- 导航取消: Type=1004, Cmd=1
- 紧急停止: Type=2, Cmd=22

### robot/ — 机器人交互层

| 文件 | 功能 |
|------|------|
| basic_client.py | TCP连接管理，发送/接收流程，断线重连 |
| telemetry.py | 遥测适配器，订阅AOS状态消息，触发回调 |
| status.py | 状态解析，Type=1002/1003/1004/1007处理 |

**遥测数据源**：
- `REAL`: 真实设备数据
- `SIMULATED`: 离线模拟数据
- `NO_DATA`: 暂无连接

### navigation/ — 导航控制

| 文件 | 功能 |
|------|------|
| service.py | 导航服务，安全门控，任务管理 |
| protocol.py | 导航报文构造（原v010.py） |

**安全门禁**：
1. read_only_mode 检查
2. 用户认证
3. 导航授权验证
4. 实际命令发送

**步态常量**：
- GAIT_FLAT_AGGRESSIVE = 0x3002（平地敏捷）
- GAIT_FLAT_STANDARD = 0x1001（平地标准）
- GAIT_PLATFORM_STANDARD = 0x1002（高台步态）

### gimbal/ — 云台控制

| 文件 | 功能 |
|------|------|
| adapter.py | 数尔WEB协议实现，自动发现，预置点管理 |

**连接优先级**：
1. manifest中配置的 gimbal_host（10.21.31.108）
2. 默认IP
3. 网络扫描（10.21.31.0/24）

### video/ — 视频流管理

| 文件 | 功能 |
|------|------|
| stream_manager.py | RTSP地址管理，FFmpeg转码，WebSocket推送 |

**视频流架构**：
```
RTSP → ffmpeg → fragmented MP4 → GET /api/v1/video/playback/{source} → <video>
```

### api/ — HTTP接口层

| 文件 | 功能 |
|------|------|
| router.py | 路由注册，16个API端点 |
| handlers.py | 认证、导航、云台状态处理器 |
| extended_handlers.py | 扩展功能处理器 |
| base_handler.py | 请求处理基类，认证中间件 |

### motion/ — 运动控制

| 文件 | 功能 |
|------|------|
| service.py | 速度控制，姿态调节，激光测距 |
| handlers.py | HTTP请求处理器 |

### auth/ — 认证鉴权

| 文件 | 功能 |
|------|------|
| store.py | 用户存储，密码哈希 |
| middleware.py | Session管理，权限校验 |

### websocket/ — WebSocket支持

| 文件 | 功能 |
|------|------|
| ws_handler.py | 视频和控制WebSocket处理器 |
| upgrade.py | RFC 6455握手实现 |

## 配置管理

运行时配置通过 `deploy/readonly-manifest.json` 管理：

```json
{
  "manifest_version": "1.0.0",
  "targets": {
    "aos_host": "10.21.31.103",
    "aos_tcp_port": 30001,
    "nos_host": "10.21.31.106",
    "gimbal_host": "10.21.31.108",
    "gimbal_port": 80,
    "gimbal_username": "admin"
  },
  "web": {
    "bind_host": "0.0.0.0",
    "port": 8080
  },
  "runtime_mode": "realtime_readonly",
  "read_only_mode": true,
  "control_enabled": false
}
```
