## 八、问题发现与修复建议

### 8.1 问题清单

| ID | 严重程度 | 区域 | 标题 | 工作量 |
|----|----------|------|------|--------|
| ISS-001 | 🟡 Medium | 登录安全 | 密码明文显示 | 简单 |
| ISS-002 | 🟢 Low | 视频体验 | 视频加载等待时间 | 简单 |
| ISS-003 | 🟢 Low | 权限反馈 | 未授权时缺少明确提示 | 简单 |

### 8.2 详细修复建议

#### ISS-001: 密码明文显示（P1）

**问题**: 登录页底部明文显示测试密码'123456'

**影响**: 生产环境中可能泄露密码信息

**修复方案**:
```html
<!-- 修改前 -->
<div class="login-footer">
  管理员账号: admin<br>
  测试密码: 123456
</div>

<!-- 修改后 -->
<div class="login-footer">
  默认管理员账号: admin<br>
  <a href="#" onclick="alert('请联系系统管理员获取初始密码');return false;">
    如何获取初始密码？
  </a>
</div>
```

**优先级**: P1（近期优化）

---

#### ISS-002: 视频加载等待时间（P1）

**问题**: 视频自动启动后需要RTSP流建立连接，可能等待3-5秒

**影响**: 用户体验轻微下降

**修复方案**:
```javascript
// 在dashboard.js的camera-placeholder中添加状态提示
<div class="camera-placeholder" id="placeholder-front">
  <div class="placeholder-icon">
    <svg>...</svg>
  </div>
  <div class="placeholder-text" id="placeholder-text-front">
    前向相机 — 就绪（点击启动）
  </div>
</div>

// 在启动视频时更新提示文本
function startVideo(source) {
  const textEl = document.getElementById(`placeholder-text-${source}`);
  if (textEl) {
    textEl.textContent = '视频连接中...';
  }
  // ... 原有逻辑
}
```

**优先级**: P1（近期优化）

---

#### ISS-003: 未授权时缺少明确提示（P2）

**问题**: 控制按钮禁用状态不明显，用户可能不知道为何无法操作

**影响**: 用户困惑

**修复方案**:
```css
/* 在style.css中添加disabled状态样式 */
button:disabled:not([data-no-tooltip]) {
  position: relative;
  cursor: not-allowed;
}

button:disabled:not([data-no-tooltip]):hover::after {
  content: attr(data-disabled-tip);
  position: absolute;
  bottom: 100%;
  left: 50%;
  transform: translateX(-50%);
  padding: 4px 8px;
  background: var(--color-bg-elevated);
  border: 1px solid var(--color-border);
  border-radius: var(--r-sm);
  font-size: var(--fs-xs);
  white-space: nowrap;
  z-index: 100;
}
```

```html
<!-- 在控制按钮上添加tooltip提示 -->
<button id="motion-forward-btn" disabled data-disabled-tip="请先授权导航">
  前进
</button>
```

**优先级**: P2（规划优化）

---

#### ISS-004: 侧边栏固定宽度（P3）

**问题**: 侧边栏固定260px，在小屏设备上可能占用过多空间

**影响**: 1024px以下屏幕内容区缩小

**修复方案**:
```css
/* 添加响应式断点 */
@media (max-width: 1024px) {
  .sidebar {
    width: 60px;
    flex: 0 0 60px;
  }
  
  .sidebar .brand strong,
  .sidebar .brand small,
  .sidebar .nav button span,
  .sidebar .side-foot {
    display: none;
  }
  
  .sidebar .nav button {
    justify-content: center;
    padding: 0;
  }
  
  .sidebar .nav button i {
    margin: 0;
  }
}
```

**优先级**: P3（长期规划）
