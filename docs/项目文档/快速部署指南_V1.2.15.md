## 立即操作步骤

### 1. 在GOS上重新部署

```bash
# SSH登录到GOS
ssh user@10.21.31.104

# 停止服务
systemctl --user stop m20-patrol-readonly.service

# 删除旧版本
rm -rf ~/m20-patrol-robot

# 解压新版本（从Telegram下载）
unzip -q ~/Downloads/m20-patrol-robot.zip -d ~/m20-patrol-robot
cd ~/m20-patrol-robot

# 重新部署
bash deploy/scripts/deploy-readonly.sh --one-shot

# 检查状态
systemctl --user status m20-patrol-readonly.service
```

### 2. 查看日志

```bash
# 实时查看日志
journalctl --user -u m20-patrol-readonly.service -f
```

**期望看到**:
```
INFO: 连接 AOS: 10.21.31.103:30001
INFO: 遥测连接成功
INFO: 已接收 10 条状态消息
```

### 3. 验证用户账户

刷新浏览器页面，右上角应显示 **admin** 而非 anonymous。

### 4. 验证数据

打开浏览器控制台（F12），查看网络请求：
```
GET /api/v1/status
```

**期望响应**:
```json
{
  "source": "REAL",
  "connected": true,
  "battery": 95,
  "motion_state": 0
}
```

## 常见问题排查

### 问题1: 仍显示anonymous

**原因**: 浏览器缓存了旧版JS文件

**解决**:
```bash
# 强制刷新页面
Ctrl+Shift+R (Windows/Linux)
Cmd+Shift+R (Mac)

# 或清除浏览器缓存
# 或访问 http://10.21.31.104:8080/?nocache=1
```

### 问题2: 连接仍失败

运行诊断脚本：
```bash
bash deploy/scripts/quick_diagnose.sh
```

### 问题3: 端口被占用

```bash
# 检查端口
ss -tlnp | grep 8080

# 杀掉占用进程
pkill -f "python.*server"

# 重新启动
systemctl --user restart m20-patrol-readonly.service
```
