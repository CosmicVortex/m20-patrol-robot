## 3. basic_server协议要点

### 3.1 端口分配

| 协议 | 端口 | 用途 |
|------|------|------|
| TCP | 30001 | 长连接，状态订阅+控制指令 |
| UDP | 30000 | 高频指令（推荐） |

### 3.2 消息格式

**APDU头部 (16字节)**:
```
| 同步字符(4) | 长度(2) | 报文ID(2) | 格式(1) | 预留(7) |
| 0xeb/0x91/0xeb/0x90 | ASDU字节数 | 请求/响应ID | XML=0/JSON=1 | 0x00 |
```

> **注意**: Type和Command字段位于ASDU载荷（JSON/XML）中，不在APDU头部。

**ASDU载荷 (JSON)**:
```json
{
  "PatrolDevice": {
    "Type": 1002,
    "Command": 6,
    "Time": "2026-08-14 00:00:00",
    "Items": { ... }
  }
}
```

### 3.3 关键Type/Command组合

| Type | Command | 方向 | 说明 |
|------|---------|------|------|
| 100 | 100 | 出 | 心跳请求（≥1Hz） |
| 1002 | 3 | 入 | 错误列表（事件驱动） |
| 1002 | 4 | 入 | 运动状态（10Hz） |
| 1002 | 5 | 入 | 设备状态（2Hz） |
| 1002 | 6 | 入 | 基础状态（2Hz） |
| 1003 | 1 | 出 | 导航任务（M20 Pro） |
| 1004 | 1 | 出 | 取消导航 |
| 1007 | 1 | 入 | 导航状态查询 |
| 1007 | 2 | 入 | 位置信息查询 |
| 1101 | 2 | 出 | 照明灯控制 |
| 1101 | 5 | 出 | 使用模式切换 |
| 1101 | 6 | 出 | 休眠模式设置 |
| 1101 | 7 | 入 | 查询休眠状态 |
| 2002 | 1 | 入 | 感知软件状态 |
| 2101 | 1 | 出 | 初始化定位 |
| 2 | 21 | 出 | 轴指令（常规模式，20Hz） |
| 2 | 22 | 出 | 状态转换 |
| 2 | 23 | 出 | 步态切换 |
| 2 | 24 | 出 | 充电控制 |
| 2 | 25 | 出 | 速度指令（导航模式） |

### 3.4 运动状态定义

| 状态值 | 名称 | 说明 |
|--------|------|------|
| 0 | 空闲 | 空闲状态，无动作，等待指令 |
| 1 | 站立 | 临时过渡状态，自动跳转到RL控制 |
| 2 | 软急停 | 关节断电，最高优先级，任意状态可触发 |
| 3 | 开机阻尼 | 开机后自动进入的阻尼状态 |
| 4 | 趴下 | 安全趴下状态 |
| 17 | RL控制 | 强化学习控制模式，唯一可执行移动和步态切换的状态 |

### 3.5 步态定义

| 十六进制 | 十进制 | 名称 | 运动模式 | 适用场景 |
|----------|--------|------|----------|----------|
| 0x1001 | 4097 | 基础 | 标准 | 室内平坦地面，手动遥控 |
| 0x1003 | 4099 | 楼梯 | 标准 | 台阶/路沿，手动遥控 |
| 0x3002 | 12290 | 平地 | 敏捷 | 自主导航 + 平地行走 |
| 0x3003 | 12291 | 楼梯 | 敏捷 | 自主导航 + 台阶跨越 |

> **注意**: 敏捷运动模式下的步态速度响应性能较好，适用于导航等自主算法开发。每次起立后或切换使用模式时，步态会自动重置为基础步态（0x1001）。

## 4. 常用诊断命令

### 4.1 GOS主机诊断

```bash
# 检查服务状态
systemctl --user status m20-patrol-readonly.service

# 查看服务日志
journalctl --user -u m20-patrol-readonly.service -f

# 健康检查
curl http://localhost:8080/api/v1/health

# 查看状态数据
curl http://localhost:8080/api/v1/status/latest | jq .

# 检查Python进程
ps aux | grep server.py

# 检查端口监听
ss -tlnp | grep 8080
```

### 4.2 网络连通性测试

```bash
# 测试AOS连接
nc -zv 10.21.31.103 30001
nc -zu 10.21.31.103 30000

# 测试NOS连接
nc -zv 10.21.31.106 22

# 测试云台连接
curl -s http://10.21.31.108/merlin/Login.cgi
ping -c 3 10.21.31.108
```

### 4.3 FFmpeg验证

```bash
# 检查FFmpeg安装
ffmpeg -version

# 探测RTSP流
ffprobe -v error -show_entries stream=codec_name,width,height,r_frame_rate -of json rtsp://10.21.31.103:8554/video1

# 测试转码
ffmpeg -i rtsp://10.21.31.103:8554/video1 -c:v libx264 -preset ultrafast -f buffer /dev/null
```

### 4.4 基本服务器通信测试


## 7. 服务管理

### 7.1 启动服务

```bash
# 一键部署
bash deploy/scripts/deploy-readonly.sh --one-shot

# 或手动启动
cd ~/m20-patrol-robot
PYTHONPATH=. python3 -m backend.app.server --manifest deploy/readonly-manifest.json
```

### 7.2 停止服务

```bash
systemctl --user stop m20-patrol-readonly.service
```

### 7.3 重启服务

```bash
systemctl --user restart m20-patrol-readonly.service
```

### 7.4 查看日志

```bash
# 实时日志
journalctl --user -u m20-patrol-readonly.service -f

# 历史日志
journalctl --user -u m20-patrol-readonly.service -n 100
```
