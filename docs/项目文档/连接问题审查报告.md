## 问题诊断

### 症状
1. Web界面显示"NO DATA / WAITING"
2. 用户显示anonymous而非admin
3. 所有遥测数据为空

### 根本原因

#### 问题1: Telemetry连接失败
```
ERROR: real connection requires protocol, firmware, and permission evidence
```

**原因**: `basic_client.py`的`connect()`方法检查了不必要的evidence和control_enabled标志。

**修复**: 移除所有evidence检查，直接尝试TCP连接。

#### 问题2: 用户显示anonymous
**原因**: `app.js`默认使用'anonymous'账户。

**修复**: 改为使用'admin'账户。

## 关键代码变更

### basic_client.py - connect()方法
```python
def connect(self, *, timeout_seconds: float = 3.0, read_only: bool = False) -> None:
    """快速部署模式：直接连接，不检查evidence"""
    if self._socket is not None:
        raise ClientStateError("client is already connected")

    try:
        connection = socket.create_connection((self.config.host, self.config.tcp_port), timeout_seconds)
        connection.settimeout(timeout_seconds)
        self._socket = connection
        logger.info("连接到 %s:%s 成功", self.config.host, self.config.tcp_port)
    except socket.timeout:
        raise ClientStateError(f"连接到 {self.config.host}:{self.config.tcp_port} 超时")
    except ConnectionRefusedError:
        raise ClientStateError(f"连接被拒绝: {self.config.host}:{self.config.tcp_port}")
    except Exception as e:
        raise ClientStateError(f"连接失败: {type(e).__name__}: {e}")
```
