#### ⚠️ 问题 P1-3: 心跳发送顺序

**位置**: `backend/app/robot/telemetry.py:219`

```python
# 当前实现
messages = client.receive_messages(timeout_seconds=0.5)
time.sleep(self.config.heartbeat_interval_s / 2)  # 0.5s
client.send_heartbeat_only()  # 在sleep后发送
```

**风险**: 如果receive阻塞接近timeout，心跳可能延迟超过1s，导致AOS判定客户端离线。

**建议**: 将心跳发送移至receive之前。
