# 心跳保活机制修复报告 V1.2.16

**日期**: 2026-08-14  
**问题**: 连接成功后无数据推送  
**根本原因**: 未发送心跳保活，AOS停止推送数据

---

## 问题分析

### 官方文档规定

根据《山猫M20 basic_server通信协议总览》:
> 无论使用 UDP 或 TCP，客户端均应以不低于 **1Hz** 的频率发送任意指令作为心跳；服务端超过 **2s** 未收到客户端任何请求则认为客户端离线，**停止向该客户端推送所有主动上报数据**。

### 当前代码问题

```python
# 原始代码 - 错误
telemetry_tx_enabled: bool = False  # ❌ 禁用了心跳发送

# telemetry.py 中的验证
if self.telemetry_tx_enabled:
    raise ValueError("telemetry transmission is disabled in this release")
```

这导致：
1. TCP连接成功后，没有发送心跳
2. AOS在2秒后认为客户端离线
3. 停止推送所有主动上报数据（Type 1002 Cmd 3/4/5/6）
4. Web界面显示"NO DATA / WAITING"

---

## 修复内容

### 1. telemetry.py - ConnectionConfig

```python
# 修复前
telemetry_tx_enabled: bool = False

def __post_init__(self):
    if self.telemetry_tx_enabled:
        raise ValueError("telemetry transmission is disabled in this release")

# 修复后
telemetry_tx_enabled: bool = True  # 必须发送心跳保活

def __post_init__(self):
    # telemetry_tx_enabled is required for heartbeat to keep TCP connection alive
```

### 2. telemetry.py - 心跳发送逻辑

```python
# 修复前
if self.config.telemetry_tx_enabled:  # 已禁用，待协议样本确认后启用
    time.sleep(self.config.heartbeat_interval_s / 2)
    heartbeat = client.build_heartbeat()
    try:
        client.send_read_only(heartbeat)
    except ClientStateError:
        logger.warning("心跳发送失败，连接可能已断开")

# 修复后
# Send heartbeat every interval (required for TCP keepalive)
# Official doc: basic_server stops pushing data after 2s without heartbeat
time.sleep(self.config.heartbeat_interval_s / 2)
heartbeat = client.build_heartbeat()
try:
    client.send_read_only(heartbeat)
except ClientStateError as e:
    logger.debug("心跳发送失败: %s", e)
except Exception as e:
    logger.warning("心跳发送异常: %s", e)
```

### 3. config.py - WebServiceConfig

```python
# 修复前
telemetry_tx_enabled: bool = False

def __post_init__(self):
    if self.telemetry_tx_enabled:
        raise ValueError("telemetry transmission is disabled in this release")

# 修复后
telemetry_tx_enabled: bool = True  # 必须发送心跳保活

def __post_init__(self):
    # telemetry_tx_enabled=True is required for heartbeat keepalive
```

## 数据流验证

### 修复前
```
GOS ──TCP连接──→ AOS
                    │
                    ├── Type 1002 Cmd 6 (BasicStatus) ❌ 不推送（无心跳）
                    ├── Type 1002 Cmd 4 (MotionStatus) ❌ 不推送
                    ├── Type 1002 Cmd 5 (DeviceStatus) ❌ 不推送
                    └── Type 1002 Cmd 3 (ErrorList) ❌ 不推送
                    
结果: source="NO_DATA", connected=False
```

### 修复后
```
GOS ──TCP连接──→ AOS
    │
    ├── 每0.5秒发送 Type 100 Cmd 100 (Heartbeat)
    │
    └── AOS收到心跳后持续推送:
        ├── Type 1002 Cmd 6 (BasicStatus) ✅ 2Hz
        ├── Type 1002 Cmd 4 (MotionStatus) ✅ 10Hz
        ├── Type 1002 Cmd 5 (DeviceStatus) ✅ 2Hz
        └── Type 1002 Cmd 3 (ErrorList) ✅ 事件驱动
        
结果: source="REAL", connected=True, battery=真实值
```
