# 快速部署修复报告 V1.2.14

**日期**: 2026-08-14  
**问题**: telemetry连接失败 - "real connection requires protocol, firmware, and permission evidence"  
**解决**: 移除evidence检查，简化连接逻辑

---

## 根本原因

`basic_client.py` 的 `connect()` 方法有两个保护门：

1. **control_enabled 检查** - 未启用控制时拒绝连接
2. **evidence 检查** - 需要协议/固件/权限证据

这两个保护在快速部署场景下是不必要的，导致无法正常连接。

---

## 修复内容

### 修改前
```python
def connect(self, *, timeout_seconds=3.0, read_only=False):
    # Read-only mode check
    if read_only:
        connection = socket.create_connection(...)
        return
    
    # Full control mode checks
    if not self.config.control_enabled:
        raise ClientStateError("control is disabled")
    
    if not all(evidence is not None for evidence in [...]):
        raise ClientStateError("real connection requires protocol, firmware, and permission evidence")
    
    connection = socket.create_connection(...)
```

### 修改后
```python
def connect(self, *, timeout_seconds=3.0, read_only=False):
    """快速部署模式：直接连接，不检查evidence"""
    try:
        connection = socket.create_connection(...)
        logger.info("连接到 %s:%s 成功", self.config.host, self.config.tcp_port)
    except socket.timeout:
        raise ClientStateError(f"连接到 {self.config.host}:{self.config.tcp_port} 超时")
    except ConnectionRefusedError:
        raise ClientStateError(f"连接被拒绝: ...")
    except Exception as e:
        raise ClientStateError(f"连接失败: ...")
```

## 控制权限仍受保护

**注意**: 虽然连接不再检查evidence，但控制操作仍然需要授权：

```python
# motion/handlers.py - 运动控制授权检查
if not self.motion_service.is_authorized():
    self.send_error_response(403, "控制未授权")
    return
```

```python
# navigation/service.py - 导航任务授权检查
if not self.nav_safety_snapshot.authorized:
    raise NavigationInterlockError("需要授权才能发送导航指令")
```
