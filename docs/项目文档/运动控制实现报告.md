## 四、安全机制

### 强制安全检查

| 检查项 | 条件 | 说明 |
|--------|------|------|
| 控制启用 | `control_enabled=True` | manifest配置 |
| 只读模式 | `read_only_mode=False` | manifest配置 |
| 授权状态 | 已通过Web UI授权 | 操作者身份记录 |
| TCP连接 | `tcp_connected=True` | 与AOS连接 |
| 硬急停 | `hes!=1` | 硬急停触发时禁止控制 |
| 保护故障 | 无保护类错误 | 电机/驱动器/电池保护 |
| 低电量 | `battery>=20%` | 低于20%禁止控制 |
| RL模式 | `motion_state==17` | 仅轴指令需要此条件 |

### 保护类错误码

```python
PROTECTIVE_FAULT_CODES = {
    0x8002, 0x8008, 0x8009, 0x8020,  # 电机/驱动器保护
    0x8103, 0x8106-0x8122,            # 电池保护
    0x8211, 0x8212,                   # CPU保护
}
```

## 六、使用示例

### Web API调用

```bash
# 1. 授权
curl -X POST http://10.21.31.104:8080/api/v1/motion/authorize \
  -H "Authorization: Bearer <token>"

# 2. 切换运动状态（站立）
curl -X POST http://10.21.31.104:8080/api/v1/motion/state \
  -H "Content-Type: application/json" \
  -d '{"state": 1}'

# 3. 轴控制（前进）
curl -X POST http://10.21.31.104:8080/api/v1/motion/axis \
  -H "Content-Type: application/json" \
  -d '{"x": 0.5, "y": 0.0, "yaw": 0.0}'

# 4. 查询状态
curl http://10.21.31.104:8080/api/v1/motion/status
```

### Python调用

```python
from backend.app.motion.service import MotionControlService

# 创建服务
service = MotionControlService(client, safety_snapshot)

# 授权
service.authorize("operator_name")

# 发送控制命令
result = service.motion_state_switch(1)  # 站立
result = service.axis_control(0.5, 0.0, 0.0)  # 前进
```

## 七、部署说明

### manifest配置

```json
{
  "runtime_mode": "realtime",
  "read_only_mode": false,
  "control_enabled": true
}
```

### 操作流程

1. 确保manifest配置正确
2. 启动服务：`python backend/app/server.py --manifest deploy/readonly-manifest.json`
3. 访问Web页面：http://10.21.31.104:8080/
4. 登录系统（默认admin/123456）
5. 点击"授权运动控制"按钮
6. 通过界面点击按钮发送控制命令

---

## 八、注意事项

1. **轴指令需RL模式**: 发送前需确认机器人处于RL控制状态（MotionState=17）
2. **软急停最高优先级**: 任意状态均可下发，可立即停止所有动作
3. **心跳未启用**: 当前telemetry_tx_enabled=False，状态数据不会持续更新
4. **安全回退**: 如遇异常，立即使用物理急停按钮
