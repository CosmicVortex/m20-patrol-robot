### 🔴 严重问题（影响技术准确性）

#### [P0] 工单API路径文档与实际注册不一致

**位置**: 
- `03-核心模块实现.md` 第269行
- `06-API参考.md` 第238行

**问题描述**:
文档描述更新工单API路径为 `PUT /api/v1/work-orders/{id}`，但实际 `router.py` 注册的路由为：
- `POST /api/v1/work-orders/create` (创建)
- `PUT /api/v1/work-orders/` (更新，通过请求体传ID)

**修复建议**:
```markdown
// 修正 03-核心模块实现.md 和 06-API参考.md
| PUT | /api/v1/work-orders/ | 更新工单 |
```
并在文档中明确说明：更新工单通过PUT请求`/api/v1/work-orders/`，在请求体中传入工单ID。

#### [P0] 导航授权命令混淆

**位置**: `05-故障排查手册.md` 第124行

**问题描述**:
在"运动控制无响应"排查步骤中，前置条件写的是：
```bash
curl -X POST http://127.0.0.1:8080/api/v1/navigation/authorize
```
这是导航授权接口，但上下文是"运动控制无响应"。运动控制应使用：
```bash
curl -X POST http://127.0.0.1:8080/api/v1/motion/authorize
```

**修复建议**:
将第124行修改为正确的运动授权接口：
```bash
curl -X POST http://127.0.0.1:8080/api/v1/motion/authorize
```
