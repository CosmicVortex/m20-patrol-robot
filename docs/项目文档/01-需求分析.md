# 需求分析

## 1. 项目背景

本项目面向**中升之星奔驰4S店**的安保巡逻场景，基于**山猫 M20 Pro** 机器狗进行二次开发，构建一套完整的机器狗安保巡逻系统。

- **交付目标**: 2026年9月
- **当前阶段**: 办公室测试
- **演示机型**: M20 Pro（GOS主机 Ubuntu 20.04.6 LTS aarch64，Python 3.8.10）
- **最终交付机型**: 山猫 S10
- **上装设备**: 热成像双光云台相机 SR-UPA810T609（数尔云台）

## 3. 非功能需求

### 3.1 性能需求

| 指标 | 要求 | 当前状态 |
|------|------|----------|
| 状态刷新频率 | ≤2秒 | ✅ 2秒轮询 |
| 视频延迟 | ≤500ms | ⚠️ 待实测 |
| 运动响应 | ≤100ms | ⚠️ 待实测 |
| 并发连接 | ≥5客户端 | ✅ 支持 |

### 3.2 可靠性需求

- **离线部署**: 无互联网依赖，所有依赖打包在离线镜像中
- **断线重连**: 基本服务器断线后自动重试连接
- **数据持久化**: SQLite存储用户和工单数据
- **安全授权**: 运动控制需Web UI显式授权

| FFmpeg版本 | 7.1+ (支持RTSP over TCP) | ⚠️ 待安装验证 |

## 5. 约束条件

1. **离线部署**: GOS主机无互联网访问，所有依赖必须离线打包
2. **Python 3.8兼容**: 代码必须兼容Python 3.8.10，不使用3.9+特性
3. **网络隔离**: 现场网络为10.21.31.0/24，所有IP固定配置
4. **品牌保留**: "中升之星奔驰"为真实部署门店，品牌名称不得修改

## 6. 验收标准

- [ ] GOS服务正常启动，健康检查通过
- [ ] 机器狗状态数据正常上报（source=REAL）
- [ ] 视频流可正常播放
- [ ] 运动控制指令可执行（需授权）
- [ ] 导航任务可下发（需地图已建）
- [ ] 云台控制正常响应
- [ ] 所有API接口返回正确格式
