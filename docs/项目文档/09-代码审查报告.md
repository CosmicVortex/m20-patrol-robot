## 八、注意事项

### 8.1 默认密码

```
admin / 123456
```

部署后应立即修改密码：
```bash
curl -X PUT http://localhost:8080/api/v1/users/password \
  -H "Content-Type: application/json" \
  -d '{"new_password": "your_secure_password"}'
```

### 8.2 硬编码IP

以下位置存在硬编码IP，部署到不同网络时需要修改：
- `backend/app/video/stream_manager.py:54-57`（RTSP地址）
- `backend/app/api/extended_handlers.py:246`（云台地址）

建议：从manifest.json读取或提供配置文件覆盖。
