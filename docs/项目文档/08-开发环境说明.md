# 开发环境说明

> 本文档说明如何在本地开发环境中搭建和调试 M20 Pro 巡逻机器人系统。

---

## 系统要求

### 硬件要求

| 组件 | 最低配置 | 推荐配置 |
|------|----------|----------|
| CPU | x86_64 双核 | 四核以上 |
| 内存 | 4GB RAM | 8GB RAM |
| 磁盘空间 | 2GB 可用 | 5GB 可用 |
| 网络 | 局域网访问 | 固定IP配置 |

### 软件要求

- **操作系统**: Ubuntu 20.04 LTS (x86_64)
- **Python**: 3.8.10+（目标环境为 3.8.10）
- **uv**: Python 包管理器（推荐）
- **git**: 版本控制工具

---

## 开发环境搭建

### 1. 克隆仓库

```bash
git clone <repository-url>
cd m20-patrol-robot
```

### 2. 安装依赖

```bash
# 使用 uv（推荐）
uv venv .venv
source .venv/bin/activate
uv pip install -r requirements.txt

# 或使用 pip
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 3. 运行测试

```bash
# 全量测试
PYTHONPATH=. uv run --with pytest pytest backend/tests/ -q

# 指定测试文件
PYTHONPATH=. uv run --with pytest pytest backend/tests/test_motion_service.py -v
```

## 本地调试模式

### 启动服务

```bash
# 使用本地脚本启动
./start.sh

# 或直接运行
python3 backend/app/server.py
```

### 配置文件

本地调试使用默认配置，如需修改：

```bash
# 编辑 manifest 配置
vim deploy/readonly-manifest.json

# 修改关键配置项
# runtime_mode: realtime_simulated（模拟数据）
# read_only_mode: false（允许控制）
# control_enabled: true（启用控制）
```

### 访问服务

```bash
# 健康检查
curl http://localhost:8080/api/v1/health

# 查看状态
curl http://localhost:8080/api/v1/status/latest
```

## 模拟模式（无实机）

### 启用模拟数据

当无真实机器狗连接时，系统可运行在模拟模式：

1. 确保 manifest 中 `runtime_mode: "realtime_simulated"`
2. 系统将生成模拟遥测数据
3. Web UI 正常显示，但数据为假值

### 模拟数据范围

| 数据类型 | 模拟内容 |
|---------|----------|
| 基础状态 | 电量随机变化，状态固定为站立 |
| 运动状态 | 位置缓慢漂移，速度为零 |
| 错误列表 | 空（无错误） |

## 端口配置

| 端口 | 服务 | 默认值 | 修改方式 |
|------|------|--------|----------|
| 8080 | Web 服务 | 8080 | manifest.json → ports.web |
| 30001 | AOS TCP | 30001 | manifest.json → ports.aos_tcp |
| 8554 | RTSP 视频 | 8554 | manifest.json → ports.rtsp |

## 常见问题

### Q1: 启动时报"端口被占用"？

```bash
# 查看占用进程
ss -tlnp | grep 8080

# 杀掉进程
sudo kill -9 <PID>
```

### Q2: 测试失败，提示"No module named 'backend'"？

```bash
# 确保 PYTHONPATH 正确
export PYTHONPATH=.
PYTHONPATH=. uv run --with pytest pytest backend/tests/ -q
```

### Q3: 如何查看实时日志？

```bash
# 运行服务时查看日志
tail -f logs/m20-patrol.log

# 或使用 journalctl
journalctl --user -u m20-patrol-readonly -f
```
