## 修复方案

### 核心原则
**Telemetry（状态订阅）与控制权限分离**

| 组件 | 职责 | 连接模式 |
|------|------|----------|
| TelemetryAdapter | 接收状态数据 | read_only=True |
| MotionService | 发送控制指令 | 需要authorization |
| NavService | 下发导航任务 | 需要authorization |

### 代码修改

#### 1. server.py - 强制telemetry使用只读模式
```python
# 修复前
read_only=self.config.read_only_mode,

# 修复后
read_only=True,  # Telemetry是只读的，控制权限由上层gate
```

#### 2. basic_client.py - 保持原有逻辑
```python
# 只读模式：允许状态订阅
if read_only:
    connection = socket.create_connection(...)
    return

# 完整控制模式：需要evidence
if not self.config.control_enabled:
    raise ClientStateError("control is disabled")
# ... evidence检查
```

```
┌─────────────────────────────────────────────────────────────┐
│ 1. Telemetry连接 (read_only=True)                           │

                           │

│    - 点击"授权控制"按钮                                     │

                           │
                           ▼
┌─────────────────────────────────────────────────────────────┐
```
