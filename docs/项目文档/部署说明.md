# 部署说明

## 前置条件

- GOS主机可达（10.21.31.104）
- FFmpeg已安装（版本7.1+）
- 网络连通性正常

## 部署步骤

### 步骤1：传输部署包

```bash
# 方式1：scp传输
scp m20-patrol-robot.zip user@10.21.31.104:/home/user/

# 方式2：MobaXterm文件浏览器拖拽上传
```

### 步骤2：SSH登录并解压

```bash
ssh user@10.21.31.104

# 解压部署包
unzip -q m20-patrol-robot.zip -d ~/m20-patrol-robot
cd ~/m20-patrol-robot
```

### 步骤3：预检

```bash
bash deploy/scripts/deploy-readonly.sh --preflight
```

### 步骤5：验证服务

```bash
# 检查服务状态
systemctl --user status m20-patrol-readonly

# 查看启动日志
journalctl --user -u m20-patrol-readonly -n 50 --no-pager

# 健康检查API
curl http://127.0.0.1:8080/api/v1/health

# 状态查询
curl http://127.0.0.1:8080/api/v1/status/latest
```

健康检查预期输出：
```json
{
  "service": "m20-patrol-web",
  "runtime_mode": "realtime_readonly",
  "read_only_mode": true,
  "connected": false,
  "source": "NO_DATA",
  "healthy": false
}
```

> **注意**: `connected=false` 和 `source=NO_DATA` 是正常的，表示遥测连接尚未建立。当AOS服务正常运行时，这些字段会变为 `connected=true` 和 `source=REAL`。

### 步骤6：访问Web界面

```bash
# 方式1：本地SSH端口转发
ssh -L 8080:localhost:8080 user@10.21.31.104
# 浏览器访问: http://localhost:8080/

# 方式2：内网直接访问
# 浏览器: http://10.21.31.104:8080/
```

**登录凭证**：
- 用户名: `admin`
- 密码: `123456`

## FFmpeg验证

```bash
# 检查FFmpeg是否已安装
command -v ffmpeg || true

# 验证RTSP支持
ffmpeg -hide_banner -demuxers 2>/dev/null | grep -qw rtsp && echo "RTSP支持: 是" || echo "RTSP支持: 否"

# 检查版本
ffmpeg -version 2>/dev/null | head -1
```

预期输出：
```
ffmpeg version 7.1
RTSP支持: 是
```

## 故障排查

### 服务未启动

```bash
# 查看服务状态
systemctl --user status m20-patrol-readonly

# 查看详细日志
journalctl --user -u m20-patrol-readonly -n 100 --no-pager

# 手动测试服务
cd ~/m20-patrol-robot
PYTHONPATH=. python3 -m backend.app.server --manifest deploy/readonly-manifest.json --verbose
```

### 端口被占用

```bash
# 检查端口占用
netstat -tlnp | grep :8080

# 服务会自动尝试备用端口（8081-8090）
```

### AOS连接失败

```bash
# 测试连接
timeout 3 bash -c 'echo > /dev/tcp/10.21.31.103/30001' && echo "连接成功" || echo "连接失败"
```

### 视频流无法播放

```bash
# 检查FFmpeg
ffmpeg -version

# 测试RTSP地址
ffprobe -v error -rtsp_transport tcp \
  -show_entries stream=codec_name \
  -of default=noprint_wrappers=1 \
  'rtsp://10.21.31.103:8554/video1'
```

## 回滚部署

```bash
# 停止并删除服务
bash deploy/scripts/deploy-readonly.sh --stop

# 清理部署目录
rm -rf ~/m20-patrol-robot
```
