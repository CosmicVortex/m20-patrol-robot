# M20 Pro 部署指南

**版本**: V1.0  
**更新**: 2026-08-16  
**适用范围**: GOS (Ubuntu 20.04 LTS aarch64) 离线部署

---

## 1. 部署前准备

### 1.1 环境要求

| 组件 | 要求 | 验证命令 |
|------|------|----------|
| GOS系统 | Ubuntu 20.04.6 LTS (aarch64) | `uname -a` |
| Python | 3.8.10（系统预装） | `python3 --version` |
| FFmpeg | 7.1+（支持RTSP over TCP） | `ffmpeg -version | head -1` |
| 磁盘空间 | ≥1GB可用 | `df -h ~` |
| 内存 | ≥4GB RAM | `free -h` |

### 1.2 网络要求

GOS需访问以下地址：

| 目标 | 地址 | 端口 | 协议 | 用途 |
|------|------|------|------|------|
| AOS | 10.21.31.103 | 30001 | TCP | basic_server 状态订阅+控制 |
| AOS | 10.21.31.103 | 8554 | RTSP | 视频流 |
| 云台 | 10.21.31.108 | 80 | HTTP | 云台控制 |
| 云台 | 10.21.31.108 | 554 | RTSP | 热成像视频 |

### 1.3 连通性验证

```bash
# 测试AOS可达性
ping -c 3 10.21.31.103

# 测试TCP端口
timeout 5 bash -c 'echo | nc -v 10.21.31.103 30001'

# 测试云台可达性
ping -c 2 10.21.31.108
timeout 5 bash -c 'echo | nc -v 10.21.31.108 80'
```

## 2. 部署流程

### 2.1 构建部署包

在联网开发机上执行：

```bash
cd /opt/data/m20-patrol-robot
bash deploy/scripts/build-offline-deploy-package.sh
```

生成文件: `m20-patrol-robot.zip`（约214MB，含FFmpeg离线包）

### 2.2 传输到GOS

```bash
# SCP传输
scp m20-patrol-robot.zip user@10.21.31.104:/home/user/

# 或通过MobaXterm SFTP拖拽
# 打开MobaXterm → SFTP → 连接10.21.31.104 → 拖拽文件到/home/user/
```

### 2.3 安装部署

```bash
# SSH登录GOS
ssh user@10.21.31.104

# 解压部署包
cd ~
unzip -q m20-patrol-robot.zip -d ~/m20-patrol-robot
cd ~/m20-patrol-robot

# 一键部署
bash deploy/scripts/deploy-readonly.sh --one-shot
```

### 2.4 FFmpeg安装（如未预装）

```bash
# 检查是否已安装
command -v ffmpeg || echo "未安装"

# 如未安装，运行离线编译安装
cd ~/m20-patrol-robot/deploy/offline/ffmpeg
bash compile-ffmpeg-arm64.sh
bash install-ffmpeg-offline.sh
```

## 5. 故障排查

### 5.1 无数据 (source=NO_DATA)

```bash
# 检查TCP连接
journalctl --user -u m20-patrol-readonly.service -n 50 --no-pager -l | grep -E "连接|遥测"

# 测试网络连通性
python3 deploy/scripts/diagnose-full-chain.py
```

### 5.2 心跳超时 (source=STALE)

检查心跳配置：
```bash
grep M20_TELEMETRY_TX_ENABLED deploy/readonly-manifest.json
```

期望: `"telemetry_tx_enabled": true`

### 5.3 服务启动失败

```bash
# 查看完整日志
journalctl --user -u m20-patrol-readonly.service -n 100 --no-pager

# 手动启动测试
cd ~/m20-patrol-robot
python3 -m backend.app.server --config deploy/readonly-manifest.json
```

## 6. 回滚方案

```bash
# 停止服务
systemctl --user stop m20-patrol-readonly.service

# 恢复旧版本
cd ~/m20-patrol-robot
git checkout <old-commit>
bash deploy/scripts/deploy-readonly.sh --install

# 启动服务
systemctl --user start m20-patrol-readonly.service
```

## 开发环境说明

### 系统要求

#### 硬件要求

| 组件 | 最低配置 | 推荐配置 |
|------|----------|----------|
| CPU | x86_64 双核 | 四核以上 |
| 内存 | 4GB RAM | 8GB RAM |
| 磁盘空间 | 2GB 可用 | 5GB 可用 |
| 网络 | 局域网访问 | 固定IP配置 |

#### 软件要求

- **操作系统**: Ubuntu 20.04 LTS (x86_64)
- **Python**: 3.8.10+（目标环境为 3.8.10）
- **uv**: Python 包管理器（推荐）
- **git**: 版本控制工具

### 开发环境搭建

#### 1. 克隆仓库

```bash
git clone <repository-url>
cd m20-patrol-robot
```

#### 2. 安装依赖

```bash
# 使用 uv（推荐）
uv venv .venv
source .venv/bin/activate
uv pip install -r requirements.txt

# 或使用 pip
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

#### 3. 运行测试

```bash
# 全量测试
PYTHONPATH=. uv run --with pytest pytest backend/tests/ -q

# 指定测试文件
PYTHONPATH=. uv run --with pytest pytest backend/tests/test_motion_service.py -v
```

### 本地调试模式

#### 启动服务

```bash
# 使用本地脚本启动
./start.sh

# 或直接运行
python3 backend/app/server.py
```

#### 配置文件

本地调试使用默认配置，如需修改：

```bash
# 编辑 manifest 配置
vim deploy/readonly-manifest.json

# 修改关键配置项
# runtime_mode: realtime_simulated（模拟数据）
# read_only_mode: false（允许控制）
# control_enabled: true（启用控制）
```

#### 访问服务

```bash
# 健康检查
curl http://localhost:8080/api/v1/health

# 查看状态
curl http://localhost:8080/api/v1/status/latest
```

### 模拟模式（无实机）

当无真实M20 Pro连接时，系统可运行在模拟模式：

1. 确保 manifest 中 `runtime_mode: "realtime_simulated"`
2. 系统将生成模拟遥测数据
3. Web UI 正常显示，但数据为假值

#### 模拟数据范围

| 数据类型 | 模拟内容 |
|---------|----------|
| 基础状态 | 电量随机变化，状态固定为站立 |
| 运动状态 | 位置缓慢漂移，速度为零 |
| 错误列表 | 空（无错误） |

### 端口配置

| 端口 | 服务 | 默认值 | 修改方式 |
|------|------|--------|----------|
| 8080 | Web 服务 | 8080 | manifest.json → ports.web |
| 30001 | AOS TCP | 30001 | manifest.json → ports.aos_tcp |
| 8554 | RTSP 视频 | 8554 | manifest.json → ports.rtsp |

### 常见问题

**Q1: 启动时报"端口被占用"？**

```bash
# 查看占用进程
ss -tlnp | grep 8080

# 杀掉进程
sudo kill -9 <PID>
```

**Q2: 测试失败，提示"No module named 'backend'"？**

```bash
# 确保 PYTHONPATH 正确
export PYTHONPATH=.
PYTHONPATH=. uv run --with pytest pytest backend/tests/ -q
```

**Q3: 如何查看实时日志？

```bash
# 运行服务时查看日志
tail -f logs/m20-patrol.log

# 或使用 journalctl
journalctl --user -u m20-patrol-readonly -f
```
