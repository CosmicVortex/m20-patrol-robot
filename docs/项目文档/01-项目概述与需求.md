# 需求分析

## 1. 项目概述

面向中升之星奔驰4S店安保巡逻场景，基于山猫 M20 Pro M20 Pro开发完整监控系统。

| 项目项 | 内容 |
|--------|------|
| 交付目标 | 2026年9月 |
| 当前阶段 | 集成测试阶段 |
| 测试环境机型 | M20 Pro（GOS Ubuntu 20.04.6 LTS aarch64，Python 3.8.10） |
| 最终交付机型 | 山猫 M20 Pro |
| 上装设备 | 云台（云台） |

## 3. 非功能需求

### 3.1 性能指标

| 指标 | 要求 | 当前状态 |
|------|------|----------|
| 状态刷新频率 | ≤2秒 | ✅ 2秒轮询 |
| 视频延迟 | ≤500ms | 🟡 待实机验证 |
| 运动响应 | ≤100ms | 🟡 待实机验证 |
| 并发连接 | ≥5客户端 | ✅ 支持 |

### 3.2 可靠性要求

- **离线部署**: 无互联网依赖，所有依赖打包在离线镜像中
- **断线重连**: basic_server断线后自动重试连接
- **数据持久化**: SQLite存储用户和工单数据
- **安全授权**: 运动控制需Web UI显式授权

### 3.3 兼容性要求

| 环境 | 要求 | 验证状态 |
|------|------|----------|
| GOS系统 | Ubuntu 20.04.6 LTS (aarch64) | 🟡 offline_verified |
| Python版本 | 3.8.10 | 🟡 offline_verified |
| FFmpeg版本 | 7.1+（支持RTSP over TCP） | 🟡 offline_verified |

## 5. 约束条件

1. **离线部署**: GOS无互联网访问，所有依赖必须离线打包
2. **Python 3.8兼容**: 代码必须兼容Python 3.8.10，不使用3.9+特性
3. **网络隔离**: 现场网络为10.21.31.0/24，所有IP固定配置
4. **品牌保留**: "中升之星奔驰"为真实部署门店，品牌名称不得修改

## 6. 验收标准

- [ ] GOS服务正常启动，健康检查通过
- [ ] M20 Pro状态数据正常上报（source=REAL）
- [ ] 视频流可正常播放
- [ ] 运动控制指令可执行（需授权）
- [ ] 导航任务可下发（需地图已建）
- [ ] 云台控制正常响应
- [ ] 所有API接口返回正确格式
