# 机器狗环境说明

## GOS主机信息

| 项目 | 值 |
|------|-----|
| 系统 | Ubuntu 20.04.6 LTS (aarch64) |
| Python | 3.8.10（系统预装） |
| FFmpeg | 7.1（离线安装，~/.local/bin/ffmpeg） |
| 部署用户 | 普通用户（非root） |

## 网络地址

| GOS | 10.21.31.104 | 8080 | Web服务 |
| AOS | 10.21.31.103 | 30001 | basic_server通信 |

## 部署路径

- 工作目录：`~/m20-patrol-robot/`
- 密码文件：`~/.config/m20-patrol/passwords.env`（权限600）
- 服务名称：`m20-patrol-readonly.service`
- 日志位置：`journalctl --user -u m20-patrol-readonly`

## 常用命令

```bash
# 查看服务状态
systemctl --user status m20-patrol-readonly

# 查看日志
journalctl --user -u m20-patrol-readonly -f

# 重启服务
systemctl --user restart m20-patrol-readonly

# 停止服务
systemctl --user stop m20-patrol-readonly
```
