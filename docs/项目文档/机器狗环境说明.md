## 禁止项

以下操作在未获书面放行前禁止执行：
- 发送心跳（Type=100）
- 发送控制命令（Type=2）
- 修改 AOS/NOS 配置
- 使用未由项目负责人确认的地址；当前清单地址为 GOS=10.21.31.104、AOS=10.21.31.103、NOS=10.21.31.106。
