## 一、主机架构

### 山猫 M20 Pro 三主机架构

```
┌─────────────────────────────────────────────────────────────────────┐
│                          内部交换机                                  │
│                                                                     │
│   ┌──────────────┐        ┌──────────────┐        ┌──────────────┐ │
│   │    AOS       │◄───────►│    NOS       │◄───────►│    GOS       │ │
│   │  运动主机     │   DDS  │  导航主机     │   DDS  │  用户开发主机 │ │
│   │  10.21.31.103│        │  10.21.31.106│        │  10.21.31.104│ │
│   └──────────────┘        └──────────────┘        └──────────────┘ │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
                           │
                     外网接入
                           │
                    10.21.31.0/24
```

### 主机角色与访问方式

| 主机 | IP 地址 | 职责 | SSH 访问 | VNC 访问 |
|------|---------|------|----------|----------|
| AOS | 10.21.31.103 | 运动控制、basic_server | ❌ 不可访问 | ❌ 不可访问 |
| NOS | 10.21.31.106 | 建图、定位、导航 | ✅ 可访问 | ✅ 可访问 |
| GOS | 10.21.31.104 | Web服务、二次开发 | ✅ 可访问 | ✅ 可访问 |

> **注意**: AOS（运动主机 10.21.31.103）不提供 SSH/VNC 访问，用户不应直接操作 AOS。

## 三、常用操作步骤

### 3.1 SSH 连接

```bash
# 连接 GOS
ssh user@10.21.31.104

# 连接 NOS
ssh user@10.21.31.106
```

### 3.2 VNC 远程桌面

NOS 和 GOS 支持 VNC 远程桌面访问：

```bash
# SSH 连接后启动 VNC 服务
x11vnc -display :0 -forever -shared -noxdamage

# 使用 MobaXterm 连接 VNC
# Session → VNC → 输入 [hostname_ip] → OK
```

### 3.3 网络配置

```bash
# 编辑网络配置文件
sudo vim /etc/netplan/config.yaml

# 应用配置生效
sudo netplan apply
```

### 3.4 机器人 WiFi 配置（需在 AOS 主机操作）

```bash
# 设置并启动 2.4GHz 热点
sudo wifi-ap-ctrl.sh setup 2G "MyWiFi" "12345678"
sudo wifi-ap-ctrl.sh start 2G

# 设置并启动 5GHz 热点
sudo wifi-ap-ctrl.sh setup 5G "MyWiFi5G" "12345678"
sudo wifi-ap-ctrl.sh start 5G
```

## 四、建图与定位

### 4.1 使用 RViz 建图（参考官方文档）

```bash
# 在 NOS 上启动建图服务
ssh user@10.21.31.106

# 启动 RViz
source /opt/robot/scripts/setup_ros2.sh
rviz2

# 通过 RViz 界面添加地图显示话题
# 话题: /grid_map_3d
```

### 4.2 初始化定位（Type=2101 Cmd=1）

**官方文档**: 《山猫M20软件开发指南V1.2.1》§1.4.1

```json
{
  "PatrolDevice": {
    "Type": 2101,
    "Command": 1,
    "Time": "2023-01-01 00:00:00",
    "Items": {
      "PosX": 0.0,
      "PosY": 0.0,
      "PosZ": 0.0,
      "Yaw": 0.0
    }
  }
}
```

**响应**:
```json
{
  "PatrolDevice": {
    "Type": 2101,
    "Command": 1,
    "Time": "2023-01-01 00:00:00",
    "Items": {
      "ErrorCode": 0  // 0=成功, 1=失败
    }
  }
}
```

> **注意**: 由于重定位需要一些时间，立即反馈的结果会是"1"（失败），这并不影响实际定位情况，建议间隔5s后查询定位状态。

### 4.3 查询定位状态（Type=1007 Cmd=2）

```json
{
  "PatrolDevice": {
    "Type": 1007,
    "Command": 2,
    "Time": "2023-01-01 00:00:00",
    "Items": {}
  }
}
```

**响应**:
```json
{
  "PatrolDevice": {
    "Type": 1007,
    "Command": 2,
    "Time": "2023-01-01 00:00:00",
    "Items": {
      "Location": 0,      // 0=定位正常, 1=定位丢失
      "PosX": 1.5,
      "PosY": 2.0,
      "PosZ": 0.0,
      "Roll": 0.0,
      "Pitch": 0.0,
      "Yaw": 0.0
    }
  }
}
```

## 五、视频流地址确认

### 5.1 本体相机（AOS）

```bash
# 使用 ffprobe 验证视频流
ffprobe -v error -show_entries format=format_name -i rtsp://10.21.31.103:8554/video1
ffprobe -v error -show_entries format=format_name -i rtsp://10.21.31.103:8554/video2
```

**预期输出**:
```
format_name=hls
```

### 5.2 数尔云台相机

```bash
# 验证云台可见光视频流
ffprobe -v error -show_entries format=format_name -i rtsp://192.168.1.108:554/id=1&type=0

# 验证云台热成像视频流
ffprobe -v error -show_entries format=format_name -i rtsp://192.168.1.108:554/id=2&type=0
```

### 5.3 视频流格式说明

| 来源 | 主码流 | 辅码流 | 热成像 |
|------|--------|--------|--------|
| RTSP URL | `rtsp://{host}:554/id=1&type=0` | `rtsp://{host}:554/id=1&type=1` | `rtsp://{host}:554/id=2&type=0` |
| 分辨率 | 3840×2160 / 1920×1080 | 1280×720 | 640×512 |
| 编码格式 | H.265 | H.265 | H.265 |
| 帧率 | 25fps (PAL) / 30fps (NTSC) | 25fps / 30fps | 25fps / 30fps |
