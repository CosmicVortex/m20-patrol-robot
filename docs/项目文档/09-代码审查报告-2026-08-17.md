## 五、发现的问题详情

### P0-1: 前端方法名不一致

**文件**: `web/js/api-service.js` vs `web/js/views/dashboard.js`

**问题**: 
- dashboard.js:694 调用 `window._api.switchMode()` 
- dashboard.js:713 调用 `window._api.motionAxis()`
- api-service.js:144 定义为 `modeSwitch()`
- api-service.js:142 定义为 `axisControl()`

**影响**: 点击方向键和模式切换按钮时无响应，控制台报错 `TypeError: window._api.switchMode is not a function`

**修复建议** (二选一):

**方案 A**: 在 api-service.js 中添加别名方法:
```javascript
// 别名（兼容 dashboard.js 调用）
async switchMode(mode) { return this.modeSwitch(mode); }
async motionAxis(x, y, yaw) { return this.axisControl(x, y, yaw); }
```

**方案 B**: 修改 dashboard.js 调用正确的 API 方法名:
```javascript
// dashboard.js:694
await window._api.modeSwitch(modeMap[mode]);  // 修改为 modeSwitch
// dashboard.js:713
await window._api.axisControl(x, y, 0);       // 修改为 axisControl
```
