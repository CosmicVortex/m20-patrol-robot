## 2. 演示流程

### 2.1 开场介绍（2分钟）

**内容**:
- 项目背景：中升之星奔驰4S店安保需求
- 系统架构：GOS + M20 Pro + 云台
- 核心功能：状态监控、视频回传、运动控制、导航管理

**话术**:
> "各位好，今天为大家展示的是基于山猫M20 Pro的安保巡逻系统。该系统已在中升之星奔驰4S店完成部署，实现24小时智能巡逻监控。"

### 2.2 Web界面演示（8分钟）

#### 2.2.1 主界面

```bash
# 打开浏览器访问
http://10.21.31.104:8080/
```

**演示要点**:
- 系统已配置自动登录admin账户，直接进入主界面
- 无需手动输入账号密码

#### 2.2.2 实时监控仪表盘

**功能点**:
- 机器人状态卡片（电量、运动状态、连接状态）
- 四路视频画面（前/后广角 + 热成像 + 云台可见光）
- 右侧控制面板（系统状态、方向选择）
- 底部控制栏（回充、技能、设置、告警）

**操作演示**:
```bash
# 查看实时状态数据
curl http://localhost:8080/api/v1/status/latest | jq .
```

#### 2.2.3 运动控制演示

**步骤**:
1. 点击"授权运动控制"按钮
2. 使用方向按键控制M20 Pro移动
3. 演示急停功能

**API演示**:
```bash
# 授权
curl -X POST http://localhost:8080/api/v1/motion/authorize \
  -H "Content-Type: application/json" \
  -d '{"operator":"admin"}'

# 前进
curl -X POST http://localhost:8080/api/v1/motion/axis \
  -H "Content-Type: application/json" \
  -d '{"x":0.5,"y":0,"yaw":0}'

# 急停
curl -X POST http://localhost:8080/api/v1/emergency/stop
```

#### 2.2.4 导航控制演示

**前提条件**: 地图已构建

**步骤**:
1. 点击"授权导航控制"
2. 输入目标坐标
3. 发送导航任务
4. 查看导航状态

**API演示**:
```bash
# 授权导航
curl -X POST http://localhost:8080/api/v1/navigation/authorize \
  -H "Content-Type: application/json" \
  -d '{"operator":"admin"}'

# 发送导航任务（注：API参数使用snake_case）
curl -X POST http://localhost:8080/api/v1/navigation/tasks \
  -H "Content-Type: application/json" \
  -d '{
    "pos_x": 1.0,
    "pos_y": 0.0,
    "pos_z": 0.0,
    "angle_yaw": 0.0,
    "map_id": 0
  }'

# 查看导航状态
curl http://localhost:8080/api/v1/navigation/status
```

#### 2.2.5 云台控制演示

**步骤**:
1. 连接云台设备
2. 调节云台角度
3. 变倍控制

**API演示**:
```bash
# 连接云台
curl -X POST http://localhost:8080/api/v1/gimbal/connect \
  -H "Content-Type: application/json" \
  -d '{"host":"10.21.31.108", "username":"admin", "password":"<your_password>"}'

# 获取云台状态
curl http://localhost:8080/api/v1/gimbal/state

# 调节方向（正确参数格式）
curl -X POST http://localhost:8080/api/v1/gimbal/move \
  -H "Content-Type: application/json" \
  -d '{"direction":"up","speed":5}'
```

### 2.4 视频回传演示（2分钟）

#### 2.4.1 多路视频展示

**演示内容**:
- 四路视频同时播放
- 视频清晰度展示

**说明**:

#### 2.4.2 视频配置

```bash
# 配置RTSP地址
curl -X POST http://localhost:8080/api/v1/video/config \
  -H "Content-Type: application/json" \
  -d '{
    "front": "rtsp://10.21.31.103:8554/video1",
    "rear": "rtsp://10.21.31.103:8554/video2"
  }'
```

## 4. 注意事项

### 4.1 安全事项

1. **急停准备**: 演示前确保急停按钮可用
2. **授权控制**: 运动控制需先授权再操作
3. **场地安全**: 确保演示区域无人员障碍

### 4.2 技术准备

1. **M20 Pro电量**: 演示前充满电（≥80%）
2. **网络稳定**: 确保GOS与AOS网络畅通
3. **地图就绪**: 导航演示需提前建图
