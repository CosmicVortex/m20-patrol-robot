## 1. 系统概述

M20 Pro巡逻机器人系统是面向中升之星奔驰4S店的安保巡逻系统。系统采用**边缘计算架构**，部署在GOS（Guard Operator Station）边缘主机上，通过basic_server协议与M20 Pro AOS通信，实现状态监控、视频回传、运动控制、导航管理等功能。

## 3. 通信协议栈

```
┌─────────────────────────────────────────────────────────────┐
│ 应用层                                                        │
│  ├── REST API (HTTP/JSON)                                    │
│  ├── WebSocket (实时推送)                                    │
│  └── basic_server 协议 (Type/Command 消息)                    │
├─────────────────────────────────────────────────────────────┤
│ 传输层                                                        │
│  ├── TCP 30001 (基本控制 + 状态订阅)                          │
│  ├── UDP 30000 (高频指令)                                    │
│  └── RTSP 8554 (视频流)                                      │
├─────────────────────────────────────────────────────────────┤
│ 网络层                                                        │
│  └── 10.21.31.0/24 (现场局域网)                               │
└─────────────────────────────────────────────────────────────┘
```

### 3.1 basic_server 协议格式

```
+--------+--------+--------+--------+--------+--------+--------+--------+
| 同步字符(4B) | 长度(2B) | 报文ID(2B) | 格式(1B) | 预留(7B) |
+--------+--------+--------+--------+--------+--------+--------+--------+
|                      ASDU Payload (JSON/XML)                         |
+---------------------------------------------------------------------+
```

**APDU头部结构** (16字节固定):
- 同步字符: `0xEB 0x91 0xEB 0x90`
- 长度: 小端2字节，ASDU字节数（不含头部）
- 报文ID: 小端2字节，请求响应匹配
- 格式: 0=XML, 1=JSON
- 预留: 7字节，填0

### 3.2 心跳机制

| 参数 | 值 | 说明 |
|------|-----|------|
| 心跳间隔 | 1.0s | ≥1Hz符合要求 |
| 心跳类型 | Type=100, Cmd=100 | 任意指令即可 |
| 超时判定 | >2s无心跳 | AOS停止推送 |
| 断线重连 | 自动 | 1秒间隔重试 |

## 5. 数据流向

### 5.1 状态订阅流（数据上行）

```
AOS (10.21.31.103:30001)
    │ Type=1002/1007 主动推送
    ▼
BasicServerClient.receive_messages()
    │ TCP接收
    ▼
FrameCodec.decode() → IncrementalDecoder.feed()
    │ APDU帧解析
    ▼
decode_patrol_message() → PatrolMessage
    │ ASDU解析
    ▼
parse_status_message() → StatusResult
    │ 状态归类
    ▼
TelemetryAdapter._process_message()
    │ 更新快照
    ▼
TelemetryAdapter.get_status_payload()
    │ API响应
    ▼
GET /api/v1/status/latest
    │ HTTP响应
    ▼
Browser (前端轮询/WebSocket)
```

### 5.2 控制指令流（数据下行）

```
Web Browser
    │ POST /api/v1/motion/axis
    ▼
AxisControlHandler
    │ 检查 read_only_mode + auth + admin
    ▼
MotionControlService
    │ 检查安全快照（运动状态、电量、急停）
    ▼
BasicServerClient.send_control()
    │ 构建APDU帧
    ▼
encode_patrol_message() → bytes
    │ TCP发送
    ▼
AOS (10.21.31.103:30001)
```

## 7. 安全架构

### 7.1 控制权限模型

```
┌─────────────────────────────────────────────────────────────┐
│ 控制权限层级                                                  │
├─────────────────────────────────────────────────────────────┤
│ Level 1: read_only_mode=true                                │
│          → 所有控制指令禁止                                   │
├─────────────────────────────────────────────────────────────┤
│ Level 2: control_enabled=false                              │
│          → Web UI控制按钮禁用，但协议层仍可发令               │
├─────────────────────────────────────────────────────────────┤
│ Level 3: auth_required=true + admin role                    │
│          → 需显式授权才能发送控制指令                         │
└─────────────────────────────────────────────────────────────┘
```

### 7.2 安全快照机制

每次控制指令发送前检查：
- 运动状态不在软急停/摔倒
- 电量 > 20%
- 导航模块无异常
- 操作员已授权
