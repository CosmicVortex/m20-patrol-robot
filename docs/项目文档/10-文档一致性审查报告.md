## 二、发现的不一致问题

### 🔴 P0 - APDU头部结构描述错误（04-机器狗环境说明.md 第68行）

**项目文档当前描述**：
```
| Length(2) | SeqNum(2) | Type(2) | Command(2) | Reserved(8) |
```

**官方文档正确描述**（《山猫M20basic_server通信协议总览.md》第43-52行）：
```
| 同步(4) | Length(2) | 报文ID(2) | 格式(1) | 预留(7) |
```

**详细说明**：
- 官方APDU头部为**16字节固定长度**，结构为：
  - 同步字符：4字节（0xeb, 0x91, 0xeb, 0x90）
  - 长度：2字节（ASDU字节段长度，小端字节序）
  - 报文ID：2字节（请求方控制，响应帧复用相同值）
  - 格式：1字节（0x00=XML, 0x01=JSON）
  - 预留：7字节（暂填0x00）

- **Type和Command不在APDU头部**，而是在ASDU载荷的JSON中：
  ```json
  {
    "PatrolDevice": {
      "Type": 1002,
      "Command": 6,
      "Time": "...",
      "Items": {...}
    }
  }
  ```

**影响**：此错误会导致开发人员误解协议格式，影响协议实现。

### 🟡 P1 - 缺少Type=2 Cmd=25速度指令说明

**官方文档说明**（《山猫M20运动控制basic_server协议.md》第214-263行）：
- Cmd=25用于导航模式下的速度指令下发
- 字段格式与Cmd=21相同（X/Y/Z/Roll/Pitch/Yaw）
- 但传输的是实际速度值（m/s/rad/s），而非归一化百分比

**项目文档现状**：
- 04-机器狗环境说明.md第100行只列出了Cmd=24（充电控制）
- 缺少Cmd=25（速度指令）的说明

**建议补充**：
```markdown
| Type | Command | 方向 | 说明 |
|------|---------|------|------|
| 2 | 25 | 出 | 速度指令（导航模式） |
```

### 3.4 运动状态定义

| 状态值 | 名称 | 说明 |
|--------|------|------|

| 1 | 站立 | 临时过渡状态，自动跳转到RL控制 |
