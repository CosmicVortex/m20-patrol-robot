### 任务三：代码实现审查

**目标**: 发现潜在bug、逻辑错误、性能问题

**审查维度**:

#### 3.1 空指针/None风险

```bash
# 查找直接属性访问
grep -rn "\w\+\.\w\+" backend/app/ --include="*.py" | grep -v "self\." | head -50
```

**检查重点**:
- 字典取值是否有`.get()`或默认值
- 对象属性访问前是否做`is not None`检查
- 返回值可能是None的地方是否有处理

#### 3.2 异常处理覆盖

```bash
# 查找bare except
grep -rn "except\s*:" backend/app/ --include="*.py"

# 查找未处理的异常
grep -rn "raise\b" backend/app/ --include="*.py" | head -30
```

**检查重点**:
- 网络操作是否有超时处理
- 文件操作是否有异常清理
- subprocess调用是否有进程清理

#### 3.3 资源泄漏

```bash
# 查找open()未用with
grep -rn "open(" backend/app/ --include="*.py" | grep -v "with "
```

**检查重点**:
- 文件句柄是否正确关闭
- socket连接是否在异常路径关闭
- subprocess进程是否被回收

#### 3.4 边界条件

```bash
# 查找可能的除零
grep -rn "/\s*\w" backend/app/ --include="*.py"
```

**检查重点**:
- 空列表/空字符串处理
- 除零风险
- 数组越界风险

#### 3.5 门禁顺序验证（关键）

```bash
# 验证所有控制端点的门禁顺序
python3 << 'PYEOF'
import inspect
import sys
sys.path.insert(0, '/opt/data/m20-patrol-robot')

from backend.app.api.handlers import (
    EmergencyStopHandler, NavigationTaskHandler,
    NavigationCancelHandler, NavigationAuthorizeHandler
)
from backend.app.motion.handlers import MotionStateHandler
from backend.app.api.extended_handlers import (
    GimbalMoveHandler, GimbalZoomHandler, GimbalAngleHandler,
    GimbalConnectHandler
)

handlers = [
    ('EmergencyStop', EmergencyStopHandler),
    ('NavAuthorize', NavigationAuthorizeHandler),
    ('NavTask', NavigationTaskHandler),
    ('NavCancel', NavigationCancelHandler),
    ('MotionState', MotionStateHandler),
    ('GimbalMove', GimbalMoveHandler),
    ('GimbalZoom', GimbalZoomHandler),
    ('GimbalAngle', GimbalAngleHandler),
    ('GimbalConnect', GimbalConnectHandler),
]

all_ok = True
for name, cls in handlers:
    source = inspect.getsource(cls.do_POST)
    rpos = source.find('read_only_mode')
    apos = source.find('_authenticate')
    
    if rpos < 0 and 'control' not in source.lower():
        print(f"✓ {name}: GET handler (no auth)")
    elif rpos >= 0 and apos >= 0 and rpos < apos:
        print(f"✓ {name}: correct order")
    elif rpos >= 0 and apos >= 0:
        print(f"✗ {name}: WRONG ORDER (read_only after auth)")
        all_ok = False
    else:
        print(f"⚠ {name}: no read_only check")

print('\nALL OK' if all_ok else 'ISSUES FOUND')
PYEOF
```

**验证标准**:
- 所有控制端点必须在auth之前检查read_only_mode
- 门禁顺序：read_only_mode → auth → admin role

## 执行约束

1. **不修改代码先汇报**: 发现问题先输出报告，待确认后修改
2. **修改必评估影响**: 每次修改必须评估对部署、测试、其他模块的影响
3. **保持文档同步**: 修改代码后必须同步更新文档
4. **区分环境**: 明确标注GOS执行命令和localhost执行命令
5. **基于事实**: 所有判断必须有代码或文档依据，不臆测
