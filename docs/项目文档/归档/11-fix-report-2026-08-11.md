## 详细修改

### 1. 视频播放功能

**前端修改** (`docs/website/index.html`):
- 添加4个`<video>`元素（front, thermal, body_front, rear）
- 添加视频控制样式（全屏、截图按钮）
- 更新`updateVideoStatus()`函数，根据状态显示/隐藏视频
- 添加`toggleFullscreen()`和`captureFrame()`函数

**视频状态逻辑**:
```
state='connected' → 显示视频元素，启用工具按钮
state='blocked' → 隐藏视频，显示BLOCKED状态
state='unverified' → 隐藏视频，显示UNVERIFIED状态
```

### 2. 紧急停止按钮

**前端修改**:
- 添加紧急停止按钮到页面底部
- 实现`handleEmergencyStop()`函数
- 按钮状态根据导航授权状态动态更新
- 点击前弹出确认对话框

**交互逻辑**:
```javascript
if (nav.authorized && nav.control_enabled) {
  btn.disabled = false;  // 可点击
} else {
  btn.disabled = true;   // 显示需授权提示
}
```

### 3. 默认数据清理

**后端修改** (`backend/app/api/extended_handlers.py`):
- `_init_default_work_orders()`: 改为保存空数组
- `_init_default_inspection_points()`: 改为保存空数组
- `_init_default_timeline()`: 改为保存空数组

**影响**: 首次访问时返回空列表，提示用户配置真实数据

### 4. 地图渲染功能

**前端修改**:
- 将地图区域改为`<canvas>`元素
- 实现`drawMap()`函数，绘制网格、巡检点、机器人位置
- 机器人位置实时刷新（2秒轮询）
- 巡检点从API获取并显示

**地图元素**:
- 网格背景（科技感）
- 巡检点（绿色圆点 + 标签）
- 机器人位置（蓝色圆点 + 方向指示）
- 坐标显示

### 5. 定时器泄漏修复

**前端修改**:
```javascript
// 集中管理所有定时器
const pollingIntervals = {
  status: setInterval(fetchStatus, 2000),
  video: setInterval(fetchVideo, 5000),
  nav: setInterval(fetchNavStatus, 10000),
  gimbal: gimbalInterval,
  clock: setInterval(tick, 1000)
};

// 页面卸载时清理
window.addEventListener('beforeunload', () => {
  Object.values(pollingIntervals).forEach(id => clearInterval(id));
});
```
