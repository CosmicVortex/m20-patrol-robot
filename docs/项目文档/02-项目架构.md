# 项目架构

## 1. 系统概述

M20 Pro巡逻机器人系统是面向中升之星奔驰4S店的安保巡逻系统。系统部署在GOS（边缘计算主机）上，通过basic_server协议与机器狗AOS通信，实现状态监控、视频回传、运动控制、导航管理等功能。

## 3. 模块划分

### 3.1 后端模块 (backend/app/)

| 模块 | 路径 | 职责 |
|------|------|------|
| server | server.py | 服务入口，组件初始化 |
| config | config.py | 配置加载，manifest解析 |
| protocol | protocol/*.py | APDU帧编解码，消息解析 |
| robot | robot/*.py | basic_server客户端，遥测适配器 |
| api | api/*.py | HTTP API处理器，路由 |
| auth | auth/*.py | 用户认证，会话管理 |
| motion | motion/*.py | 运动控制服务 |
| navigation | navigation/*.py | 导航控制服务 |
| gimbal | gimbal/*.py | 数尔云台控制 |
| video | video/*.py | RTSP视频流管理 |
| websocket | websocket/*.py | WebSocket服务 |

### 3.2 前端模块 (docs/website/)

| 模块 | 路径 | 职责 |
|------|------|------|
| HTML | index.html | 页面结构 |
| CSS | css/style.css | 样式定义 |
| JS | js/*.js | 应用逻辑 |
| Views | js/views/*.js | 各视图实现 |

## 4. 数据流向

### 4.1 状态订阅流

```
AOS (10.21.31.103:30001)
    │ Type=1002/1007 上报
    ▼
basic_server Client
    │ 解析为内部数据结构
    ▼
TelemetryAdapter
    │ 缓存最新状态（每2秒）
    ▼
StatusLatestHandler
    │ GET /api/v1/status/latest
    ▼
Web Browser
```

### 4.2 控制指令流

```
Web Browser
    │ POST /api/v1/motion/axis
    ▼
AxisControlHandler
    │ 检查 read_only_mode + auth + admin
    ▼
MotionControlService
    │ 检查安全快照（运动状态、电量、急停）
    ▼
BasicServerClient
    │ Type=2 Cmd=21 发送
    ▼
AOS (10.21.31.103:30001)
    │ 转发至运动控制模块
    ▼
机器狗执行动作
```

### 4.3 视频流流程

```
AOS RTSP (10.21.31.103:8554)
    │ RTSP流
    ▼
FFmpeg (GOS)
    │ 转码为 fragmented MP4（H.264）
    ▼
VideoStreamManager
    │ WebSocket推送
    ▼
Web Browser
    │ <video> 标签播放
```

## 6. 技术选型

| 技术 | 选型 | 理由 |
|------|------|------|
| 后端语言 | Python 3.8 | GOS预装，无需额外依赖 |
| 网络框架 | http.server（标准库） | 无第三方依赖，适合离线部署 |
| 数据库 | SQLite | 单文件，无需额外服务 |
| 视频转码 | FFmpeg 7.1 | 支持RTSP over TCP |
| 前端框架 | 原生JS | 无构建依赖，纯静态文件 |
| 协议格式 | JSON | basic_server官方支持 |

## 7. 安全设计

1. **门禁顺序**: read_only_mode → auth → admin，三层防护
2. **控制授权**: 运动/导航控制需Web UI显式授权
3. **审计日志**: 所有控制操作记录操作人和时间
4. **密码安全**: bcrypt哈希存储，默认密码提示修改
