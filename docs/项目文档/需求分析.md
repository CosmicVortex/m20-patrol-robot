# 需求分析

## 项目目标

面向奔驰4S店的机器狗安保巡逻系统，实现室内外巡逻、视频回传、状态监控、异常告警等功能。

**演示机型**: M20 Pro（GOS主机，Ubuntu 20.04.6 LTS, aarch64, Python 3.8.10，固件V1.1.8）  
**交付机型**: 山猫 M20 Pro
**上装设备**: 热成像双光云台相机 SR-UPA810T609（数尔云台）  
**通信协议**: basic_server（TCP 30001）  
**部署位置**: GOS 主机（10.21.31.104）

## 验收规则

### 离线验收

```bash
PYTHONPATH=. uv run --with pytest pytest -q
```

- 模拟页面返回 `source=SIMULATED`、`connected=false`
- 真实接入返回 `source=REAL`、`connected=true`

### 真实接入条件

1. M20 Pro 型号、固件版本已确认
2. V1.2.1 与固件差异已记录
3. basic_server 权限已批准
4. 状态数据可读且新鲜度可判定
5. 现场安全条件已确认
6. 书面放行

## 实际开发接口

### 状态订阅（Type=1002）

| Command | 内容 | 频率 |
|---------|------|------|
| 3 | 异常列表 | 事件驱动 |
| 4 | 运控状态（Roll/Pitch/Yaw/OmegaZ/LinearX/Y/Height） | 10Hz |
| 5 | 设备状态（BatteryList、DeviceTemperature、CPU） | 2Hz |
| 6 | 基础状态（MotionState/Gait/Charge/HES/ControlUsageMode） | 2Hz |

### 导航控制

| Type | Command | 功能 |
|------|---------|------|
| 1003 | 1 | 下发单点导航任务 |
| 1004 | 1 | 取消导航任务 |
| 1007 | 1 | 查询导航任务状态 |
| 1007 | 2 | 获取位置信息 |
| 1007 | 3 | 导航异常上报（≥V1.1.8） |
| 2002 | 1 | 感知软件状态 |

### 导航请求参数（V1.2.1 §3.1）

```json
{
  "Value": 0,      // 导航任务目标点编号（默认值0）
  "MapID": 0,      // 目标点所在栅格地图编号（默认值0）
  "PosX": 0.0,     // 目标点坐标 X（米）
  "PosY": 0.0,     // 目标点坐标 Y（米）
  "PosZ": 0.0,     // 目标点坐标 Z（米）
  "AngleYaw": 0.0, // 目标点朝向（弧度）
  "PointInfo": 1,  // 目标点类型：过渡点=0, 任务点=1, 充电点=3
  "Gait": 0x3002,  // 步态：平地敏捷=0x3002, 楼梯敏捷=0x3003
  "Speed": 0,      // 速度：正常=0, 低速=1, 高速=2
  "Manner": 0,     // 运动方式：前进行走=0, 倒退行走=1
  "ObsMode": 0,    // 停避障：开启=0, 关闭=1
  "NavMode": 1     // 导航方式：直线导航=0, 自主导航=1
}
```

## 安全边界

- 控制能力独立于状态订阅，默认关闭
- 导航/运动需书面放行
- 所有控制操作记录审计日志
- 模拟状态标识 `SIMULATED`，不得显示为真实
