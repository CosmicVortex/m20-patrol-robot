### 6.2 部署流程

```bash
# 1. 传输部署包到GOS
scp -r m20-patrol-robot.tar.gz user@10.21.31.104:/home/user/

# 2. SSH登录GOS并解压
ssh user@10.21.31.104
tar -xzf m20-patrol-robot.tar.gz
cd m20-patrol-robot

# 3. 编译安装FFmpeg（首次必需）
cd deploy/offline/ffmpeg
bash compile-ffmpeg-arm64.sh
bash install-ffmpeg-offline.sh

# 4. 执行一键部署
cd ..
bash deploy/scripts/deploy-readonly.sh --one-shot

# 5. 验证服务
curl http://localhost:8080/api/v1/health
curl http://localhost:8080/api/v1/status/latest
```

**评估**: ✅ 部署流程完整，脚本齐全，支持一键部署。
