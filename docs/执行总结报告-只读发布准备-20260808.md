## 4. 已完成的主要修复

### 4.1 只读遥测安全边界

- `DashboardConfig` 构造阶段拒绝：
  - `read_only_mode=false`
  - `control_enabled=true`
  - `telemetry_tx_enabled=true`
- `ConnectionConfig` 拒绝遥测发送配置。
- 默认运行模式保持只读。
- 只读状态输出包含 control、TX、连接、帧数和数据年龄等字段。

### 4.2 视频生命周期

- FFmpeg watcher/drainer 创建异常时执行进程清理。
- stop 取消路径等待清理任务完成。
- 处理进程自然退出、terminate、kill、超时和 `ProcessLookupError`。
- watcher/drainer 按 source 隔离。
- cleanup 遍历进程和后台任务，避免孤儿 task 或进程引用。
- 相关 Python 3.8 时间 API 兼容性已处理。

### 4.3 安装与回滚安全门禁

- install、rollback 拒绝 root 用户执行。
- apply 入口要求：
  - GOS 本机地址包含 `10.21.31.104`；
  - `systemctl --user` 可用；
  - `ip` 命令可用；
  - 冲突服务 `m20-patrol-realtime.service` 不得 active 或 enabled；
  - 安装源工作树必须干净。
- 只读 manifest 校验：
  - realtime read-only 模式；
  - control=false；
  - telemetry RX=true；
  - telemetry TX=false；
  - GOS/AOS/NOS 固定地址；
  - TCP/UDP/RTSP/Web 端口；
  - Web 绑定地址；
  - freshness 阈值；
  - 不包含凭据。
- systemd unit 关键字段执行一致性校验。
- install dry-run 针对指定 commit 归档内容校验，不再校验可能含未提交修改的当前工作树。
- install、rollback 拒绝 `current` 为普通文件、目录或其他非软链接对象。
- `current` 目标必须解析到 `TARGET_ROOT/releases/<40位小写SHA>`。
- install、rollback 拒绝 systemd unit 路径为软链接。
- 安装失败时清理临时 release。
- 安装和回滚保存并恢复 current、unit、服务 active/enabled 状态。
- systemd 状态查询、daemon-reload、服务恢复失败不会静默忽略。
