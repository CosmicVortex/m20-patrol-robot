## 2. 相关接口介绍

### 2.1 basic_server 协议

所有设备的当前状态可通过 basic_server 协议的以下接口返回：

| 接口 | 频率 | 作用 |
|---|---|---|
| Type=1002, Cmd=4 | 10Hz 主动上报（依赖心跳保活） | 获取机身姿态角、速度、高度<br>获取腿部关节角度和轮关节转速 |
| Type=1002, Cmd=5 | 2Hz 主动上报（依赖心跳保活） | 获取电池状态<br>获取关节电机和驱动器温度<br>获取照明灯开关状态<br>获取 GNSS 卫星定位数据<br>获取激光雷达开关状态<br>获取相机开关状态<br>获取 GNSS 模块开关状态<br>获取 CPU 状态 |
| Type=1002, Cmd=6 | 2Hz 主动上报（依赖心跳保活） | 获取硬急停触发状态<br>获取电源管理模式（供电电池数量） |
| Type=1101, Cmd=2 | 请求-响应 | 控制前后照明灯开关 |

> 具体的定义请参考《软件开发指南》。

### 2.2 ROS2 相关话题

各分页涉及的 ROS2 话题汇总如下，具体定义参见 [ROS 2 / DDS 话题速查](./ros2-topic-reference.md)：

| 话题名 | 说明 |
|---|---|
| `/LIDAR/POINTS` | 默认情况下为前后拼接的雷达点云，可配置为前雷达点云 |
| `/LIDAR/POINTS2` | 默认情况下不生效，可配置为后雷达点云 |
| `/IMU` | IMU 数据（已坐标变换） |
| `/GPS` | GNSS 定位数据 |
| `/JOINTS_DATA` | 关节状态反馈 |
| `/JOINTS_CMD` | 下发关节控制指令 |
| `/HES_STATUS` | 硬急停触发状态 |

## 3. 使用模式与休眠模式

使用模式管理和休眠模式管理是设备管理的重要组成部分：

### 3.1 使用模式管理

- **常规模式**：支持轴指令运动控制
- **导航模式**：支持导航任务执行
- **辅助模式**：支持遥控+避障

### 3.2 休眠模式管理

- **手动休眠**：通过 Type=1101, Cmd=6 控制
- **自动休眠**：可配置无消息下发后的自动休眠时间
- **唤醒流程**：通过发送任意指令唤醒
- **状态查询**：通过 Type=1101, Cmd=7 查询休眠状态及设置

## 4. 传感器数据获取方法

### 4.1 照明灯控制

```json
// 开启前后照明灯
{
  "PatrolDevice": {
    "Type": 1101,
    "Command": 2,
    "Time": "2026-08-06 14:00:00",
    "Items": {
      "Front": 1,
      "Back": 1
    }
  }
}
```

### 4.2 IMU 数据获取

通过 Type=1002, Cmd=4 的 `MotionStatus` 字段获取：
- `Roll` / `Pitch` / `Yaw`：姿态角度（rad）
- `OmegaZ`：Z 方向角速度（rad/s）

或通过 ROS2 话题 `/IMU` 获取（200Hz）。

### 4.3 GNSS 数据获取

通过 Type=1002, Cmd=5 的 `GPS` 字段获取：
- `Latitude` / `Longitude`：经纬度（deg）
- `Speed`：地面速度（km/h）
- `Course`：航向（deg）
- `FixQuality`：定位质量
- `NumSatellites`：卫星数量
- `Altitude`：海拔高度（m）

或通过 ROS2 话题 `/GPS` 获取。

### 4.4 关节数据获取

通过 Type=1002, Cmd=4 的 `MotorStatus` 字段获取：
- `Joint`：16 个关节的角度/转速数组
- 各关节独立字段：`LeftFrontHipX`, `LeftFrontHipY`, 等

或通过 ROS2 话题 `/JOINTS_DATA` 获取。
