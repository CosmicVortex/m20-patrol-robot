## 一、产品概述

SR-UPA810T609是一款集热成像和可见光于一体的双光谱云台相机，采用SONY超大靶面sensor，支持10倍光学变倍和640×512热成像。

### 核心特性

- 800万像素可见光摄像机，10倍光学变倍
- 640×512氧化钒非制冷红外探测器
- 测温范围：-20℃～150℃（默认）/ 100℃～550℃
- 支持H.265编码
- 单IP同时输出可见光和热成像视频
- 支持ONVIF、GB28181协议
- 内置3.2T智能算力，可扩展行业算法

## 五、WEB API接口

**基础URL**: `http://{host}:80/merlin`

### 5.1 登录认证

```
POST /merlin/Login.cgi?Type=WEB&Expires=30
Authorization: Basic {base64(admin:password)}
```

响应：
```json
{
  "Session": "0x7f74105010",
  "result": {
    "message": "OK",
    "num": 200
  }
}
```

### 5.2 心跳包

```
GET /merlin/Heartbeat.cgi
```

### 5.3 RPY角度控制

```
POST /merlin/SetPtzangle.cgi
{
  "Angle": {
    "yaw": 5,      // -280°～280°
    "pitch": 5,    // -115°～40°
    "roll": 0
  }
}
```

### 5.4 状态获取

```
GET /merlin/GetFlyStateInfo.cgi
```

响应：
```json
{
  "FlyInfo": { "yaw": 0, "pitch": 0, "roll": 0 },
  "CamerInfo": { "zoom": 1 }
}
```

### 5.5 变倍控制

```
GET /merlin/PtzCtrl.cgi?operation=10&speed=5&channelno=0&value=0
// operation: 9=变倍-, 10=变倍+
```

### 5.6 直接变倍

```
GET /merlin/ZoomCtrl.cgi?zoom=8&channelno=0
```

### 5.7 运动方向控制

```
POST /merlin/SetPtzDirection.cgi
{
  "Direction": {
    "ptz_opt": "up",  // up/down/left/right/stop
    "speed": 5        // 1-20
  }
}
```

### 5.8 设备状态

```
GET /merlin/GetDeviceState.cgi
```

响应：
```json
{
  "DeviceState": {
    "SystemState": {
      "CPU": 9,
      "MEM": 48,
      "totalvolume": "0GB",
      "undistributed": "0GB"
    }
  }
}
```

## 七、在M20 Pro项目中的使用

```python
from backend.app.gimbal.adapter import SoarGimbalAdapter, GimbalConfig

# 配置云台
config = GimbalConfig(
    host="192.168.1.108",
    port=80,
    username="admin",
    password=os.environ.get("M20_GIMBAL_PASSWORD", "123456"),
    rtsp_url="rtsp://192.168.1.108:554/id=1&type=0",
    thermal_rtsp_url="rtsp://192.168.1.108:554/id=2&type=0",
)

# 创建适配器
gimbal = SoarGimbalAdapter(config)

# 登录并获取状态
if gimbal.login():
    state = gimbal.get_state()
    print(f"云台状态: {state}")
```
