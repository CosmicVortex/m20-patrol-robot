## 1. 操作系统信息

### 1.1 查看操作系统版本

山猫 M20 各主机运行 **Ubuntu 20.04 LTS**。

```bash
cat /etc/os-release
```

### 1.2 查看软件包版本

```bash
cat /var/opt/robot/release_note.json
```

### 1.3 查看各应用程序版本

```bash
sudo dpkg -l | grep 'built using CMake' | awk '{print $2, $3}' | column -t
```

## 2. 应用程序日志

### 2.1 日志路径

应用程序日志存放在各主机的 `/var/opt/robot/log/[日期]/` 目录下。

### 2.2 常见日志查看方式

以 basic_server 为例：

```bash
# 实时查看日志
tail -f /var/opt/robot/log/2026_0601/Basic_server.2026_0601.log

# 关键字搜索
grep 'keyword' /var/opt/robot/log/2026_0601/Basic_server.2026_0601.log

# 忽略大小写搜索
grep -i 'ERROR' /var/opt/robot/log/2026_0601/Basic_server.2026_0601.log

# 查看关键字上下文（前后 5 行）
grep -C 5 'keyword' /var/opt/robot/log/2026_0601/Basic_server.2026_0601.log

# 分页浏览
less /var/opt/robot/log/2026_0601/Basic_server.2026_0601.log
```

### 2.3 急停快照

当急停触发时，系统会自动保存急停前 5 分钟的所有运行数据。

| 项目 | 说明 |
|---|---|
| 触发条件 | 仅当软急停或硬急停触发时生成 |
| 时间窗口 | 急停触发前 5 分钟 |
| 存储路径 | `/var/opt/robot/log/system/snapshot_时间戳.csv` |

#### 字段说明

| 字段类别 | 含义 |
|---|---|
| Time s | 时间戳（秒） |
| Joint Pos 0~15 | 16 个关节的实际位置（弧度） |
| Joint Vel 0~15 | 关节实际速度 |
| Joint Tor 0~15 | 关节实际力矩/电流 |
| Joint status 0~15 | 关节状态码（正常/错误/过温/过流等） |
| Joint motor temp 0~15 | 关节电机温度 |
| Joint driver temp 0~15 | 关节驱动器温度 |
| Joint Cmd Pos 0~15 | 关节期望位置（控制指令） |
| Joint Cmd Vel 0~15 | 关节期望速度 |
| Joint Cmd Tor 0~15 | 关节前馈力矩 |
| Joint control 0~15 | 关节控制模式（位置/速度/力矩控制） |
| IMU acc_x/y/z | 三轴加速度（m/s²） |
| IMU roll/pitch/yaw | 姿态角（弧度） |
| IMU omega_x/y/z | 三轴角速度 |
| Steer x/y/z/roll/pitch/yaw | 本体期望位姿（控制目标） |
| Target/Current State | 目标/当前运动状态 |
| Target/Current Gait | 目标/当前步态 |

> **用途：** 急停时保存过去 5 分钟的所有数据，用于分析急停前发生了什么——是关节过温？姿态异常？还是其他原因？

### 2.4 关键运行数据

系统会持续记录机器狗运行期间的关键健康数据。

| 项目 | 说明 |
|---|---|
| 触发条件 | 持续记录，机器狗运行期间一直写入 |
| 存储路径 | `/var/opt/robot/log/system/时间戳.csv` |

#### 字段说明

| 字段类别 | 含义 |
|---|---|
| Time s | 时间戳 |
| Battery L/R Voltage | 左/右电池电压（V） |
| Battery L/R Current | 左/右电池电流（A），正=放电，负=充电 |
| Battery L/R Percentage | 左/右电池电量百分比（%） |
| Battery L/R Cycles | 左/右电池充放电循环次数 |
| Battery L/R Protected State | 电池保护状态（过放/过充/过温保护等） |
| Battery L/R Mos State | MOS 管状态（导通/断开——是否在供电） |
| Battery L/R Temperature_1~4 | 左右电池各 4 个温度传感器（℃） |
| Battery L/R cell_voltage_1~20 mv | 左右电池各 20 串电芯电压（mV） |
| Cpu Temperature 0~2 | AOS 主控板 3 个 CPU 温度传感器（℃） |
| Cpu Frequency 0~3 MHz | 4 个 CPU 核心当前频率（MHz） |
| Joint 0~15 Motor Temperature | 16 个关节电机温度 |
| Joint 0~15 Driver Temperature | 16 个关节驱动器温度 |

> **用途：** 持续监控整个机器狗的健康状态，特别是关节和电池。

## 3. 系统资源监控

### 3.1 htop 查看实时计算资源

htop 是一个交互式的系统资源监控工具，适合快速定位资源占用高的进程。

**功能特点：**
- 实时显示系统资源：CPU、内存、交换分区使用率
- 进程列表：按 CPU 或内存排序，显示 PID、用户、优先级、命令等
- 树形视图：查看进程父子关系
- 交互操作：无需输入 PID 即可直接 kill、renice 进程

**界面说明：**
- 顶部彩色条：CPU/内存使用率，不同颜色代表用户态、系统态、I/O 等待等
- 进程列表：按当前排序字段高亮显示
- 底部快捷键菜单：F1~F10 的功能提示

#### 常用指令

```bash
# 启动 htop
htop

# 启动时只显示某个用户的进程
htop -u username

# 启动时按树形显示
htop -t
```

#### 常用快捷键

| 按键 | 功能 |
|---|---|
| F1 / ? | 帮助 |
| F3 / / | 搜索进程 |
| F4 / \ | 按名称过滤 |
| F5 / t | 树形视图 |
| F6 | 选择排序字段（CPU、内存、PID 等） |
| F9 / k | kill 进程（先选中，再选信号） |
| F10 / q | 退出 |
| u | 按用户过滤 |
| M | 按内存排序 |

> 在山猫主机上排查某个模块 CPU/内存占用异常时，直接 htop 后按 F4 过滤进程名（如 planner、localization）即可快速定位。

### 3.2 系统监控指标

system_status_node 持续采集系统状态指标，可查看 system_status_node 的日志来获取系统状态指标的数据记录。

| 指标 | 采集频率 | 来源 |
|---|---|---|
| CPU 利用率 | 1 Hz | /proc/stat |
| CPU 温度 | 1 Hz | /sys/class/thermal |
| CPU 主频 | 1 Hz | /sys/devices/system/cpu |
| 内存使用 | 0.1 Hz | /proc/meminfo |
| 网络状态 | 0.05 Hz | /proc/net/dev |
| 文件系统 | 0.01 Hz | df |

**告警阈值：**
- CPU 占用率超过 **80%** 时，会打印 WARN 日志并输出占用最高的 5 个进程
- **rte_checker 告警阈值：**
  - CPU 告警阈值：80.0%
  - 内存告警阈值：60.0%

## 4. 服务管理

### 4.1 查询服务状态

```bash
sudo systemctl status XXX.service   # XXX 为服务名称
```

### 4.2 启停服务

```bash
# 临时关闭服务
sudo systemctl stop XXX.service

# 临时开启服务
sudo systemctl start XXX.service
```

### 4.3 开机自启动管理

```bash
# 禁用服务（取消开机自启动）
sudo systemctl disable XXX.service

# 启用服务（开机自启动）
sudo systemctl enable XXX.service
```

> **注意：** 每次 OTA 后，各服务的开机自启动设置将恢复为出厂默认状态，需要再次执行 disable 指令以禁用相应服务。

## 5. 常用运维命令汇总

### 5.1 日志相关

```bash
# 查看 basic_server 实时日志
tail -f /var/opt/robot/log/$(date +%Y_%m%d)/Basic_server.$(date +%Y_%m%d).log

# 搜索错误日志
grep -i 'error' /var/opt/robot/log/$(date +%Y_%m%d)/*.log

# 查看系统状态日志
sudo journalctl -u system_status_node -f
```

### 5.2 资源监控

```bash
# 实时监控资源使用
htop

# 查看 CPU 核心使用率
mpstat -P ALL 1

# 查看内存使用
free -h

# 查看磁盘使用
df -h

# 查看特定进程资源占用
ps aux | grep planner
```

### 5.3 服务管理

```bash
# 查看服务状态
sudo systemctl status basic_server.service

# 重启服务
sudo systemctl restart basic_server.service

# 禁用服务
sudo systemctl disable basic_server.service
```

### 5.4 版本查询

```bash
# 查看软件包版本
cat /var/opt/robot/release_note.json

# 查看应用程序版本
sudo dpkg -l | grep 'built using CMake' | awk '{print $2, $3}' | column -t

# 查看固件版本
cat /etc/os-release
```

## 6. 故障排查流程

### 6.1 CPU/内存占用过高

```bash
# 1. 启动 htop 查看资源使用
htop

# 2. 按 CPU 排序，定位高占用进程
# 按 F6 选择 Sort by → CPU %

# 3. 过滤特定进程
# 按 F4，输入进程名（如 planner）

# 4. 查看详细资源占用
top -p <PID>
```

### 6.2 通信异常

```bash
# 1. 检查服务状态
sudo systemctl status basic_server.service

# 2. 查看日志
tail -f /var/opt/robot/log/$(date +%Y_%m%d)/Basic_server.$(date +%Y_%m%d).log

# 3. 检查网络连接
ping 10.21.31.103  # AOS
netstat -an | grep 30000
netstat -an | grep 30001
```

### 6.3 关节异常

```bash
# 1. 查看关节状态日志
grep -i 'joint' /var/opt/robot/log/$(date +%Y_%m%d)/*.log

# 2. 检查急停快照
ls -la /var/opt/robot/log/system/snapshot_*.csv

# 3. 查看关键运行数据
cat /var/opt/robot/log/system/$(date +%Y%m%d)_*.csv | head -100
```
