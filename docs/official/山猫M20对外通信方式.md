# 山猫 M20 对外通信方式

**文档版本：** V1.0.0  
**适用型号：** 山猫 M20、山猫 M20 Pro  
**适用软件包版本：** V1.1.7 及以后  
**更新日期：** 2026-06-18

---

## 概述

山猫 M20 提供两种对外通信方式：

1. **basic_server 协议** — 基于 APDU/ASDU 帧协议的 UDP/TCP 接口
2. **ROS2 接口** — 基于 DrDDS 中间件的话题/服务

开发者应根据接入条件、功能需求和技术栈选择合适的方式。

---

## 1. 通信架构概述

```
┌─────────────────────────────────────────────────────────────────────┐
│                     机器人内部通信架构                                │
│                                                                     │
│   ┌──────────────┐        ┌──────────────┐        ┌──────────────┐ │
│   │     AOS      │◄───────►│     NOS      │◄───────►│     GOS      │ │
│   │  运动主机     │  DDS   │  导航主机     │  DDS   │  用户开发主机 │ │
│   └──────┬───────┘        └──────────────┘        └──────┬───────┘ │
│          │                                                │          │
│          │               basic_server                    │          │
│          └────────────────────────────────────────────────┘          │
│                              │                                       │
└──────────────────────────────┼───────────────────────────────────────┘
                               │
                    ┌──────────┴──────────┐
                    │                     │
                    ▼                     ▼
              UDP 30000              TCP 30001
              无连接/低延迟           长连接/可靠传输
              适合高频速度指令        适合任务下发/状态订阅
```

机器人系统内部各进程之间通过 **DrDDS**（基于 FastDDS 的中间件）通信，与 ROS2 Foxy 兼容；对外由 basic_server 提供运行在 UDP/TCP 基础上的通信协议，统一遵循 APDU/ASDU 结构。

---

## 2. 两种通信方式对比

| 维度 | basic_server 协议 | ROS2 接口 |
|---|---|---|
| **传输层** | UDP / TCP | FastDDS 话题/服务 |
| **协议规范** | APDU/ASDU 帧协议（JSON/XML） | ROS2 标准/自定义消息类型 |
| **功能覆盖** | 运动控制、定位导航、设备控制、自主充电等 | 传感器数据获取、定位、运动控制等 |
| **跨版本兼容** | 协议层稳定，一般情况下向后兼容 | ROS2 版本（Foxy/Humble/Jazzy）和不同的DDS可能不兼容 |
| **典型场景** | 远程控制集成、业务系统对接、APP 开发 | 机载算法开发、自定义导航和SLAM开发 |

## 3. basic_server 通信协议简介

### 3.1 基本信息

basic_server 通信协议基于 APDU/ASDU 帧结构，其服务端运行在 AOS 主机的 basic_server 进程上：

| 端口 | 协议 | 特点 | 适用场景 |
|---|---|---|---|
| 30000 | UDP | 无连接、低延迟 | 高频速度指令（≥20Hz） |
| 30001 | TCP | 长连接、可靠传输 | 任务下发和状态订阅 |

### 3.2 协议核心要素

每帧结构：

```
┌─────────────────────────────────────────────────────────────────────┐
│ 帧头 (4B) │ 数据长度 (2B) │ 消息ID (2B) │ 格式 (1B) │ 保留 (7B) │ ASDU (N字节) │
│ EB 91 EB 90│ 小端字节序   │ 小端字节序  │ 0x00=XML │ 0x00...  │ JSON/XML    │
└─────────────────────────────────────────────────────────────────────┘
```

- **帧头**：固定为 `EB 91 EB 90`（4字节）
- **数据长度**：ASDU 字节段长度，小端字节序，最大 65535 字节
- **消息ID**：每帧报文唯一标识，请求方控制，响应帧复用相同值，小端字节序
- **格式**：ASDU 数据格式类型，`0x00=XML`，`0x01=JSON`
- **保留**：7字节，暂填 0
- **ASDU**：应用服务数据单元，以 `PatrolDevice` 为根对象

### 3.3 ASDU 结构

ASDU 以 `PatrolDevice` 为根对象，包含：

```json
{
  "PatrolDevice": {
    "Type": 1002,
    "Command": 6,
    "Time": "2026-08-06 14:00:00",
    "Items": {
      "BasicStatus": {
        "MotionState": 0,
        "Gait": 12290,
        "Charge": 0,
        "HES": 0,
        "ControlUsageMode": 1,
        "Direction": 0,
        "OOA": 0,
        "PowerManagement": 0,
        "Sleep": 0,
        "Version": "PRO"
      }
    }
  }
}
```

| 字段 | 含义 |
|---|---|
| Type | 消息类型（业务大类） |
| Command | 消息命令码（子命令） |
| Time | 报文发送时间，本地时区，格式：YYYY-MM-DD HH:MM:SS |
| Items | 消息所携带的参数项 |

### 3.4 数据格式

支持 **JSON**（推荐）和 **XML** 两种数据格式：

- **JSON**：处理性能更快，数据结构更全面，支持更多消息类型
- **XML**：传统格式，兼容性更好

### 3.5 连接方式

开发者可以在以下位置与 basic_server 通讯：

1. **内部主机**：在机器人内部主机（GOS/NOS）上直接连接 AOS（10.21.31.103）
2. **外部主机**：通过以下方式连接到机器人局域网 31 网段后，与 basic_server 通讯：
   - WiFi AP（机器人热点）
   - 31 网段的对外以太网网口

## 4. ROS2/DDS 接口简介

### 4.1 基本信息

机器人内部使用 DrDDS（基于 FastDDS 的中间件）进行跨进程通信，部分常见必要话题已对外开放，以供开发者在 GOS 主机或外接主机上使用。

### 4.2 开放话题列表

#### 传感器数据

| 话题名 | 描述 | 频率 | 备注 |
|---|---|---|---|
| `/LIDAR/POINTS` | 点云数据 | 10Hz | 需管理员权限，依赖 multicast-relay.service |
| `/IMU` | IMU 数据 | 200Hz | - |

#### 定位与导航

| 话题名 | 描述 | 频率 |
|---|---|---|
| `/ODOM` | 实时定位位姿获取 | 10Hz |
| `/initialpose` | 重置定位 | 事件驱动 |
| `/LOCATION_STATUS` | 定位状态获取 | 2Hz |

#### 运动控制

| 话题名 | 描述 | 频率 |
|---|---|---|
| `/MOTION_INFO` | 运动状态和步态读取 | 20Hz |
| `/MOTION_STATE` | 运动状态切换 | 事件驱动 |
| `/GAIT` | 步态切换 | 事件驱动 |
| `/NAV_CMD` | 速度指令下发 | 10Hz |

#### 设备管理

| 话题名 | 描述 |
|---|---|
| `/HES_STATUS` | 硬急停状态 |

### 4.3 版本兼容说明

山猫 M20/M20 Pro 使用的操作系统版本为 **Ubuntu 20.04**，其上运行的 DDS 为 **DrDDS**（基于 FastDDS 封装），ROS 版本均为 **ROS2 Foxy**。

> **注意：** 如果想让外部主机和山猫 M20 正常通信，需保证底层都使用 Fast DDS 作为通信标准。

但机器人本体主机的 ROS 2 Foxy 版本可能会与外部主机的 ROS 2 版本存在兼容性差异，导致看不到话题或数据解析错误。如必须使用 ROS 程序，需参考以下 ROS 版本兼容关系：

| 山猫M20/M20 Pro版本 | 外部主机ROS版本 |
|---|---|
| V1.1.7 以前版本 | ROS2（Foxy、Humble） |
| V1.1.7 及以后版本 | ROS 2（Foxy、Humble、Jazzy） |

### 4.4 使用限制

> **注意：** 出于计算资源和系统完整性的考虑，开发者应尽量避免在 AOS 或 NOS 主机上开发。推荐将二次开发程序部署在 **GOS** 主机上。

## 5. 调用逻辑差异

部分功能在两种通信方式下的调用逻辑存在差异，需要依据各个功能模块的具体说明来开发调用。

### 5.1 选择建议

| 需求场景 | 推荐方式 | 原因 |
|---|---|---|
| 快速集成业务系统 | basic_server | 协议稳定，跨版本兼容性好 |
| 开发自定义导航算法 | ROS2/DDS | 可直接订阅传感器话题 |
| 高频速度控制（≥20Hz） | basic_server UDP | 低延迟，无连接开销 |
| 状态订阅和任务下发 | basic_server TCP | 可靠传输，长连接 |
| 机载感知算法开发 | ROS2/DDS | 原生 ROS2 接口 |
| 移动应用开发 | basic_server | 标准网络协议，跨平台 |

### 5.2 混合使用

某些场景下可以混合使用两种通信方式：

```
┌─────────────────────────────────────────────────────────────┐
│                      混合通信架构                              │
│                                                             │
│   ┌─────────────┐    basic_server    ┌─────────────┐       │
│   │  外部业务   │◄──────────────────►│   GOS       │       │
│   │  系统集成   │                    │ (用户主机)  │       │
│   └─────────────┘                    └──────┬──────┘       │
│                                             │               │
│                              ROS2/DDS 话题   │               │
│                                             ▼               │
│                                    ┌─────────────┐          │
│                                    │  自定义节点  │          │
│                                    │ (感知/业务) │          │
│                                    └──────┬──────┘          │
│                                           │                  │
│                              ┌────────────┼────────────┐     │
│                              │            │            │     │
│                              ▼            ▼            ▼     │
│                        ┌─────────┐  ┌─────────┐  ┌─────────┐ │
│                        │   AOS   │  │   NOS   │  │  外部   │ │
│                        │ 运动主机 │  │ 导航主机 │  │  主机   │ │
│                        └─────────┘  └─────────┘  └─────────┘ │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
