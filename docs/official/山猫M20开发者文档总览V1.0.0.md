# 山猫 M20 开发者文档总览

**文档版本：** V1.0.0  
**适用型号：** 山猫 M20、山猫 M20 Pro  
**适用软件包版本：** V1.1.7 及以后  
**更新日期：** 2026-06-18

---

## 概述

山猫 M20 是云深处科技（DEEPRobotics）推出的四轮足机器人平台，本文档主要介绍如何基于该平台进行 **感知算法二次开发** 与 **业务层应用开发**。

### 相关代码仓库

运控算法开发请参考 GitHub 仓库：

- **DeepRoboticsLab/sdk_deploy**: Sim-to-sim and sim-to-real deployment for Deep Robotics Robots, currently supporting M20 and Lite3
- **DeepRoboticsLab/rl_training**: RL_Training Repo Based on Isaaclab

安卓 APP 开发请参考 GitHub 仓库：

- **DeepRoboticsLab/m20-android-sdk**: Android SDK for Lynx M20 — provides robot connection, state management, remote control, and controller input integration for building custom control apps.

---

## 这份文档解决什么问题？

**目标：** 让感知算法工程师与业务系统工程师在 **不试探、不踩坑** 的前提下完成开发。

## 系统能力一览

| 能力 | 实现方式 |
|---|---|
| 多步态切换 | 强化学习步态控制（平地、楼梯） |
| 多协议接入 | UDP / TCP（基于 APDU/ASDU）+ ROS2 / DDS |
| 3D SLAM 建图（仅山猫 M20 Pro 支持） | LiDAR + IMU |
| 实时定位（仅山猫 M20 Pro 支持） | 预建地图基础上 LiDAR + IMU + GNSS 融合 |
| 导航规划（仅山猫 M20 Pro 支持） | 全局规划（可选）+ 局部规划 + 动态避障 |
| 自主充电（选配） | 反光柱识别 + 动态停障 + 状态机控制 |
