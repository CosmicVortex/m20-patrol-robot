## 典型段落优化对比

### 优化前
```
该页面不会连接机器人、不发送心跳、不下发导航，也不会把模拟数据标为真实状态。
```

### 优化后
```
本页面运行于模拟模式：不建立设备连接、不发送心跳包、不下发控制指令，
模拟数据仅用于界面展示，不视为真实状态。
```
