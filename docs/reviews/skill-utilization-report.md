3. 使用 `docs-architecture-governance` 规范化文档命名和结构

**预期效果**:

- 消除 AI 生成痕迹
- 文档架构清晰可维护

### 2. 代码质量提升 (优先级: 高)

**组合技能**: `code-reviewer` + `code-complexity` + `python-type-hints-guide`

2. 使用 `python-type-hints-guide` 补充类型注解
3. 使用 `code-reviewer` 进行代码审查

**重点关注**:
- `dashboard_realtime.py` (633行，可能过长)

**预期效果**:

### 3. Web 界面升级 (优先级: 高)

**实施步骤**:

import re, os
for root, dirs, files in os.walk('backend'):
    for f in files:
        if f.endswith('.py'):
            path = os.path.join(root, f)
            with open(path) as fp:
                lines = fp.readlines()
            # 统计函数长度
            funcs = [(m.start(), m.group()) for m in [re.search(r'\s*def \w+', l) for l in lines] if m]
            for i in range(len(funcs)-1):
                if funcs[i+1][0] - funcs[i][0] > 50:
                    print(f'{path}:{funcs[i][0]+1} ({funcs[i+1][0]-funcs[i][0]} lines)')
