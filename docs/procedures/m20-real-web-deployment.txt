M20 Pro 真实 Web 只读基础测试部署说明

文档用途

本文件用于将离线程序包复制到 M20 Pro/GOS 主机，执行只读模式部署和基础测试。
机器人主机已安装 unzip，因此不需要 python-unzip.py。

重要安全边界

本程序包仅用于 realtime_readonly 遥测联调。

M20_RUNTIME_MODE=realtime_readonly
M20_READ_ONLY_MODE=true
M20_CONTROL_ENABLED=false
M20_TELEMETRY_TX_ENABLED=false

程序不会发送运动、导航、定位重置、充电、云台或巡检任务指令。
未取得现场证据前，不得把 Web 页面中的视频、地图、路线、点位或告警视为真实数据。

一、传输文件

程序压缩包内已经包含部署脚本、systemd 模板、manifest、后端代码、Web 资源和测试文件。
不要单独安装部署脚本，也不要从 GitHub 下载依赖。

建议传输以下文件：

1. m20-patrol-robot-deploy.zip
2. m20-patrol-robot-deploy.sha256（可选，用于校验压缩包完整性）
3. 本 TXT 部署说明（可选）

可以通过 U 盘、局域网文件传输或其他现场批准方式复制到 GOS。
机器人未连接公网时，不执行 git clone、pip install、uv install 或在线下载。

二、GOS 现场前置检查

在 GOS 主机执行以下命令，并保存完整原始输出：

hostname
id
uname -a
python3.8 --version
ip -4 addr
ip route
systemctl --user show-environment
command -v unzip
nc -zvw3 10.21.31.103 30001
nc -zvw3 10.21.31.103 8554

必须现场确认：

GOS 地址：10.21.31.104
AOS 地址：10.21.31.103
NOS 地址：10.21.31.106
Python：3.8.10
用户级 systemd 可用
AOS TCP 30001 可达
RTSP 8554 的可达性
实机软件、固件和协议服务版本

任一项不满足时，不执行安装。保留完整输出并标记为 BLOCKED 或 UNVERIFIED。

三、校验压缩包

将压缩包放到 GOS 临时目录，例如 /tmp：

cd /tmp

如果同时复制了旁车 SHA256 文件，执行：

sha256sum -c m20-patrol-robot-deploy.sha256

输出文件名后带 OK 才表示压缩包与发送时的文件一致。

SHA256 文件不是 shell 脚本，也不需要执行权限。
它只是一个文本校验记录，格式通常为：

HASH值  文件名

SHA256 用于发现文件在传输、复制或存储过程中是否损坏或被替换。
它不能证明机器人已经连接，也不能证明部署成功，更不能替代真机测试。

即使没有旁车 SHA256 文件，也可以在 GOS 上计算当前文件的摘要并记录：

sha256sum m20-patrol-robot-deploy.zip

本版本压缩包的 SHA256 以随包提供的 .sha256 文件为准，不要手工改写。

四、解压程序包

机器人主机已安装 unzip，直接执行：

cd /tmp
unzip m20-patrol-robot-deploy.zip
cd m20-patrol-robot

如果提示目标目录已经存在，不要使用覆盖选项继续执行。
应删除或改用一个新的临时解压目录，避免覆盖旧程序或旧测试材料。

例如：

cd /tmp
mkdir -p m20-release-NEW
cd m20-release-NEW
unzip ../m20-patrol-robot-deploy.zip
cd m20-patrol-robot

压缩包内部已经包含以下部署脚本：

deploy/scripts/deploy-readonly.sh
deploy/scripts/install-gos.sh
deploy/scripts/rollback-gos.sh
deploy/scripts/start.sh
deploy/scripts/collect-readonly-info.sh

deploy/python-unzip.py 仅作为无 unzip 环境的备用工具，本机已安装 unzip 时不需要使用它。

五、解压后文件校验

在解压后的程序根目录执行：

cd /tmp/m20-release-NEW/m20-patrol-robot
test -f deploy/readonly-manifest.json
test -f deploy/package.sha256
sha256sum -c deploy/package.sha256

所有受控文件都应显示 OK。
如果任一文件显示 FAILED，不得继续部署。

六、离线 dry-run

仍在程序根目录执行：

bash deploy/scripts/deploy-readonly.sh --dry-run

必须看到：

DRY_RUN=true
NO_FILES_WRITTEN=true
NO_SYSTEMD_CHANGE=true
NO_NETWORK_SIDE_EFFECT=true

dry-run 不写入持久部署目录，不修改 systemd，不发送机器人网络数据。

七、目标主机 preflight

确认 dry-run 通过后执行：

bash deploy/scripts/deploy-readonly.sh --preflight

必须看到：

PY38_RUNTIME_CHECK=PASS
TARGET_IDENTITY_CONFIRMED=PASS
TELEMETRY_TX_ENABLED=false
CONTROL_ENABLED=false
WEB_REALTIME_ENABLED=true
PREFLIGHT=PASS

如果缺少 python3.8、GOS 地址不匹配、systemd 不可用、冲突服务状态未知或冲突服务未禁用，命令必须失败。
不要绕过失败门禁。

八、管理员密码

首次启动如需创建 admin 账户，临时设置现场负责人提供的密码：

export M20_ADMIN_PASSWORD='现场负责人设置的至少12位密码'

密码不得写入 Git、程序包、文档、命令输出或日志。

九、一键只读安装、启动和健康检查

执行：

bash deploy/scripts/deploy-readonly.sh --one-shot

命令只有在严格健康接口确认真实遥测后才应成功。
健康条件包括：

runtime_mode=realtime_readonly
source=REAL
connected=true
bytes_received>0
valid_frames>0
frame_valid=true
message_parsed=true
status_accepted=true
telemetry_fresh=true
data_state=REAL_FRESH
age_ms 小于 stale_after_seconds * 1000
control_enabled=false
telemetry_tx_enabled=false

没有真实遥测时失败是预期的安全行为，不要修改脚本绕过。

测试完成后清除环境变量：

unset M20_ADMIN_PASSWORD

十、访问 Web

默认地址：

http://10.21.31.104:8080/

笔记本不能直接访问时，可以在笔记本建立 SSH 隧道：

ssh -L 8080:10.21.31.104:8080 <gos-user>@10.21.31.104

然后打开：

http://127.0.0.1:8080/

十一、必须保存的现场证据

请保存以下完整原始输出：

1. hostname、id、uname -a
2. python3.8 --version
3. ip -4 addr、ip route
4. systemctl --user show-environment
5. nc 对 AOS 30001 和 RTSP 8554 的结果
6. sha256sum 校验结果
7. unzip 解压结果
8. deploy-readonly.sh --dry-run
9. deploy-readonly.sh --preflight
10. deploy-readonly.sh --one-shot
11. systemctl --user status m20-patrol-readonly.service
12. Web health 接口原始 JSON
13. Web status/latest 接口原始 JSON
14. 服务日志

十二、状态判定

离线测试通过只能标记为：

offline_verified

只有在 GOS 上确认 Python 3.8.10、固定地址、systemd、AOS 有效帧、消息解析和新鲜遥测后，才能标记为：

runtime_integrated
field_verified

现场负责人明确确认并接受结果后，才能标记为：

field_accepted

云端无法访问 GOS，因此云端不会宣称真机部署、真实遥测、视频或现场验收完成。
