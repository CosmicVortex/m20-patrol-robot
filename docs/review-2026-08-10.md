### 7.1 立即修复（P0）

### 7.2 高优先级改进（P1）

1. **API 路由器依赖注入**：
   ```python
   # api/router.py route() 方法中补充
   handler.gimbal_adapter = self.gimbal_adapter
   handler.video_manager = self.video_manager
   ```

2. **更新系统服务模板**：
   ```ini
   # deploy/systemd/m20-patrol-readonly.service
   ExecStart=%h/.local/share/m20-patrol-robot/current/.venv/bin/python -m backend.app.server
   ```
   或直接使用部署脚本生成的服务文件（不依赖模板）。

3. **实现密码自动生成**：
   在 `deploy-readonly.sh` 中添加：
   ```bash
   if [ -z "$M20_ADMIN_PASSWORD" ]; then
       M20_ADMIN_PASSWORD=$(openssl rand -base64 12)
       echo "M20_ADMIN_PASSWORD=$M20_ADMIN_PASSWORD" > "$CONFIG_DIR/passwords.env"
   fi
   ```

4. **WebSocket 集成**：
   需要选择实现方案：
