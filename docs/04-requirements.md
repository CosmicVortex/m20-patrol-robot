## 双场地验收顺序

1. **华翔智行办公室**：现场建图、整包备份、哈希记录、定位核验、单点自主导航和无控制视频取证
2. **办公室回归**：使用同一地图完成重复路线、异常停止和恢复记录
3. **东莞中升之星奔驰 4S 店**：清理办公室资产引用，重新建图并单独备份，重新采集点位
4. **门店回归**：在门店地图上重新完成定位、路线和视频验收
5. 两地证据齐全后，才评审多点巡逻任务编排和后续 S10 迁移

地图资产不以文件名作为身份依据，必须以现场核验的地图身份、生成时间、场地和整包 SHA-256 联合记录。

## 办公室阶段必须完成的功能

办公室阶段必须在现场安全放行下完成完整闭环：

1. 依据 V0.0.1 手册在 NOS 完成办公室地图

7. 定位丢失、通信超时、急停、保护故障、低电量或人员进入区域时自动拒绝/暂停
8. 单点导航、取消、状态、视频切换、异常停止和恢复形成现场记录
9. 全部通过后，才允许迁移至东莞门店重新建图

## 验收规则

### 离线验收（当前可执行）

- `PYTHONPATH=. uv run --with pytest pytest -q` 全部通过
- APDU/ASDU 测试不建立网络连接，不发送机器人报文
- 模拟页面返回 `source=SIMULATED`、`connected=false`、`control_enabled=false`
- 部署脚本默认不启用机器人控制，服务只绑定回环地址

### 真实接入前置条件（必须全部满足）

以下条件全部满足前，不得建立 AOS 长连接、发送心跳或下发导航：

- M20 Pro 实际型号、系统/固件版本和主机身份已由现场输出确认
- V1.2.1、V0.1.0 和当前固件的差异已记录
- basic_server 第三方连接权限和真实脱敏样本已取得
- 地图、定位、异常、急停和电量状态均可读且可判定新鲜度
- 现场隔离区、操作员、安全观察员和停止流程已确认
- 现场负责人书面放行

## 当前已实现功能

### R-06 真实状态订阅 ✅

**AOS 地址：** 10.21.31.103（已确认）
**固件版本：** V1.1.8（最低要求）

**可接收的状态消息：**
- `1002/6` 基础状态（MotionState/Gait/Charge/HES）
- `1002/4` 运控状态（Roll/Pitch/Yaw/速度）
- `1002/5` 设备状态（BatteryList/CPU温度/GPS）
- `1002/3` 异常列表（errorCode/component）
- `1007/1` 导航状态查询响应
- `1007/2` 位置查询响应
- `1007/3` 导航异常主动上报（≥V1.1.8）
- `2002/1` 导航感知状态查询响应

**心跳保活：**
- 客户端每 1Hz 发送心跳（Type=100, Command=100）
- 服务端 2 秒无请求停止主动上报
- 客户端 3 秒无响应判定断线

### R-07 视频接入 🟡

**RTSP 地址（已确认）：**

**需现场确认：**

- [ ] 编码格式：H.264 还是 H.265
- [ ] 分辨率、帧率、码率

**实现状态：**
- 视频流管理器已实现（stream_manager.py）
- ffprobe 探测功能已实现
- FFmpeg 拉流框架已实现
- Web 端视频切换待前端开发

### R-08 单点导航控制 🟡

**Web 授权流程：**
1. 操作员点击"授权导航"按钮
2. 系统检查安全条件：
   - control_enabled=True
   - TCP 已连接
   - 定位正常
   - 避障开启
   - 急停未触发
   - 无保护异常
   - 电量≥20%
   - 当前无导航任务
3. 点击"前往点位"，输入坐标
4. 系统发送 1003/1 导航命令
5. 审计日志记录所有操作

**安全门控：**
- 导航命令默认关闭
- Web UI 显式授权后才能发送
- 授权后仍可取消
- 异常时自动停止导航
