# M20 Patrol Robot

云深处山猫 M20 Pro 奔驰 4S 店巡逻机器狗二次开发项目。

## 当前范围

- M20 Pro 机器人状态适配
- SR-UPA810T609 热成像双光云台适配
- 巡逻任务编排
- 视频与照片回传
- 地图与实时轨迹展示
- 异常告警与后续 S10 迁移

## 安全边界

本项目涉及移动机器人。未确认设备型号、软件版本、官方接口、急停状态、定位状态、现场隔离区和操作人员前，不得发送运动、步态、定位重置或导航指令。

仓库不得提交：

- 设备、SSH、相机或平台密码
- Token、私钥、证书
- 现场真实地图和视频
- 未脱敏日志及客户数据
- 无转载授权的厂商原始文档
